## Часть I. Объектив Fujinon 23mm f/2

### Характеристики объектива

| Параметр | Значение |
|----------|----------|
| Фокусное расстояние | 23mm |
| Эквивалент (35mm) | 35mm |
| Максимальная диафрагма | f/2 |
| Минимальная диафрагма | f/16 |
| Количество лепестков | 9 (скруглённые) |
| Минимальная дистанция фокусировки | 10 см (макро) |
| Конструкция | 8 элементов в 6 группах |
| Асферические элементы | 2 |

### Почему 35mm?

Фокусное расстояние 35mm (в эквиваленте) считается «золотой серединой»:

```
                    Угол обзора
                         │
  24mm ─────────────────────────────── Широкий угол
        │ Пейзаж, архитектура
        │
  35mm ───────────[X100VI]───────────── Стандартный
        │ Уличная фотография, репортаж
        │
  50mm ─────────────────────────────── Нормальный
        │ Портреты, повседневная съёмка
        │
  85mm ─────────────────────────────── Телеобъектив
        │ Портреты
```

**Преимущества 35mm:**
- Близок к углу зрения человеческого глаза
- Универсален: от пейзажей до портретов
- Позволяет включить контекст, но не слишком широк
- Классика уличной фотографии

### Работа с фиксированным объективом

#### «Зум ногами»

Без зума вы учитесь:
- Думать о композиции до того, как поднимете камеру
- Двигаться ради лучшего кадра
- Видеть сцену «глазами 35mm»

> 💡 **Совет**: Через несколько недель съёмки вы начнёте видеть кадры в формате 35mm даже без камеры в руках.

#### Дистанция и перспектива

```
Близко к объекту:              Далеко от объекта:
┌──────────────────┐           ┌──────────────────┐
│     ╭───╮        │           │   ╭─╮    ╭─╮    │
│    ╱     ╲       │           │   │ │    │ │    │
│   │  👤   │      │           │   │👤│    │🏠│    │
│    ╲     ╱       │           │   │ │    │ │    │
│     ╰───╯        │           │   ╰─╯    ╰─╯    │
│                  │           │                  │
│ • Объект крупно  │           │ • Объект мельче  │
│ • Фон размыт     │           │ • Больше в кадре │
│ • Искажения      │           │ • Меньше боке    │
└──────────────────┘           └──────────────────┘
```

### Цифровой телеконвертер

X100VI имеет функцию цифрового зума без потери качества (благодаря 40-мегапиксельной матрице):

| Режим | Эквивалент | Разрешение | Применение |
|-------|------------|------------|------------|
| Без конвертера | 35mm | 40 MP | Стандарт |
| x1.4 | 50mm | ~20 MP | Портреты |
| x2.0 | 70mm | ~10 MP | Детали, портреты |

**Настройка:**
`MENU → Настройка съёмки → Цифровой телеконв.`

Или назначьте на функциональную кнопку для быстрого доступа.

> ⚠️ **Важно**: Это кроп, а не настоящий зум. Качество хорошее, но не злоупотребляйте x2.0.

### Конвертеры для X100VI

Для X100VI существуют оптические конвертеры:

| Конвертер | Эквивалент | Особенности |
|-----------|------------|-------------|
| **WCL-X100 II** | 28mm | Широкоугольный |
| **TCL-X100 II** | 50mm | Телеконвертер |

Они крепятся на адаптер AR-X100 и сохраняют качество оптики.

### Минимальная дистанция фокусировки

Объектив X100VI фокусируется с **10 см**! Это позволяет:
- Снимать детали, текстуры
- Делать «полумакро» снимки
- Фотографировать еду с близкого расстояния

**Для макросъёмки:**
1. Переключитесь в режим ручного фокуса (M)
2. Подойдите максимально близко
3. Используйте помощник фокусировки (пикинг)

## Часть II. Накамерная вспышка

### Встроенная вспышка X100VI

X100VI оснащена компактной встроенной вспышкой:

```
        ╭────────╮
       ╱   ⚡    ╲  ← Выдвижная вспышка
      ╱          ╲
     │    ◯◯◯     │ ← Видоискатель
     │            │
     │   [    ]   │ ← Объектив
     └────────────┘
```

**Характеристики:**
- Ведущее число: ~7 (ISO 200)
- Угол покрытия: соответствует 35mm
- Режим синхронизации: до 1/4000 с (с электронным затвором)

**Как открыть вспышку:**
Нажмите рычажок на левой стороне камеры (рядом с видоискателем).

### Режимы работы вспышки

`MENU → Настройка вспышки → Режим вспышки`

#### AUTO — Автоматический
- Вспышка срабатывает, когда камера считает нужным
- Удобно, но непредсказуемо

#### Принудительная вспышка (Forced Flash)
- Срабатывает всегда
- Используйте для заполняющей вспышки днём

#### Медленная синхронизация (Slow Sync)
- Вспышка + длинная выдержка
- Проявляет и объект (вспышка), и фон (окружающий свет)

#### Синхронизация по задней шторке (Rear Sync)
- Вспышка срабатывает в конце экспозиции
- Естественные следы движения

#### Подавитель эффекта красных глаз
- Серия предвспышек перед основной
- Зрачок сужается, глаза не красные

### Заполняющая вспышка (Fill Flash)

**Проблема:** При съёмке портрета против солнца лицо оказывается в тени.

**Решение:** Вспышка «заполняет» тени на лице!

```
Без вспышки:                С заполняющей вспышкой:
┌──────────────────┐        ┌──────────────────┐
│      ☀️          │        │      ☀️          │
│                  │        │                  │
│    ╭────╮        │        │    ╭────╮   ⚡   │
│   ╱ 🌑  ╲       │        │   ╱ 😊  ╲       │
│  │ тёмно │      │        │  │ светло │      │
│   ╲      ╱       │        │   ╲      ╱       │
│    ╰────╯        │        │    ╰────╯        │
└──────────────────┘        └──────────────────┘
```

**Настройки:**
1. Откройте вспышку
2. Установите режим «Принудительная вспышка»
3. Уменьшите мощность на -1...-2 EV (`MENU → Настройка вспышки → Компенс. вспышки`)

### Отражённая вспышка

Прямая вспышка создаёт жёсткие тени. Решение — отражение:

```
Прямая вспышка:              Отражённая вспышка:
         │                         ╱│
         ⚡                        ⚡ │
         │                       ╱  │
         ▼                      ▼   │потолок
    ╭────────╮               ╭────────╮
   ╱ жёсткие ╲             ╱  мягкий  ╲
  │   тени    │           │    свет    │
   ╲         ╱             ╲          ╱
    ╰────────╯               ╰────────╯
```

**Проблема:** Встроенная вспышка X100VI не поворачивается.

**Решения:**
1. Используйте внешнюю вспышку с поворотной головой
2. Держите белую карточку над вспышкой (часть света отразится)
3. Используйте диффузор (рассеиватель)

### Диффузоры и модификаторы

Для смягчения света от встроенной вспышки:

| Модификатор | Эффект | Потеря света |
|-------------|--------|--------------|
| Белая салфетка | Минимальное смягчение | ~0.5 EV |
| Пластиковый диффузор | Умеренное смягчение | ~1 EV |
| Мини-софтбокс | Хорошее смягчение | ~1.5 EV |

### Вспышка и бленда

> ⚠️ **Важно!** При использовании вспышки снимите бленду! Она создаст тень в нижней части кадра.

### Синхронизация на коротких выдержках

X100VI поддерживает синхронизацию вспышки до **1/4000 с** с электронным затвором!

Это позволяет использовать вспышку даже при ярком солнце с открытой диафрагмой.

**Настройка:**
1. `MENU → Настройка съёмки → Тип затвора` → **Электронный** или **Авто**
2. Вспышка будет синхронизироваться на любой выдержке

## Часть III. ГРИП (Глубина резко изображаемого пространства)

### Что такое ГРИП

**ГРИП** — это диапазон расстояний, в котором объекты выглядят резкими на снимке.

```
           ГРИП
    ├──────────────┤
    │              │
────┼──────────────┼────────────→ расстояние
    │              │
  начало         конец
  резкой         резкой
  зоны           зоны
```

### Визуализация ГРИП

```
Малая ГРИП (f/2):
────────────────────────────────────→
          ↑        ↑
      нерезко    резко     нерезко
                  👤
         [  ГРИП  ]

Большая ГРИП (f/11):
────────────────────────────────────→
    ↑                           ↑
   резко                       резко
   🏔️           👤              🏠
        [────── ГРИП ──────]
```

### Факторы, влияющие на ГРИП

#### 1. Диафрагма

| Диафрагма | ГРИП | Эффект |
|-----------|------|--------|
| f/2 | Очень малая | Сильное размытие фона |
| f/4 | Малая | Заметное размытие |
| f/5.6 | Средняя | Умеренное размытие |
| f/8 | Большая | Большинство в резкости |
| f/11+ | Очень большая | Почти всё резко |

#### 2. Расстояние до объекта

```
Близко (1м):              Далеко (10м):
   ГРИП = 0.2м              ГРИП = 5м

   [      ]                [                    ]
     👤                              👤
```

Чем ближе объект — тем меньше ГРИП!

#### 3. Фокусное расстояние

На X100VI это фиксировано (23mm), но для понимания:
- Широкоугольные = большая ГРИП
- Телеобъективы = малая ГРИП

35mm (эквивалент X100VI) даёт умеренную ГРИП.

### ГРИП на X100VI: практические значения

При фокусировке на 2 метра:

| Диафрагма | ГРИП | От | До |
|-----------|------|----|----|
| f/2 | 0.35м | 1.85м | 2.20м |
| f/2.8 | 0.50м | 1.79м | 2.29м |
| f/4 | 0.71м | 1.71м | 2.42м |
| f/5.6 | 1.02м | 1.60м | 2.62м |
| f/8 | 1.49м | 1.47м | 2.96м |
| f/11 | 2.22м | 1.33м | 3.55м |
| f/16 | 3.77м | 1.14м | 4.91м |

### Гиперфокальное расстояние

**Гиперфокальное расстояние** — это расстояние фокусировки, при котором ГРИП простирается от половины этого расстояния до бесконечности.

Для X100VI (23mm):

| Диафрагма | Гиперфокальное | ГРИП от |
|-----------|----------------|---------|
| f/8 | 4.1м | 2.05м до ∞ |
| f/11 | 2.9м | 1.45м до ∞ |
| f/16 | 2.0м | 1.0м до ∞ |

**Практическое применение:**
- Установите f/8
- Сфокусируйтесь на 4 метра
- Всё от 2 метров до бесконечности будет резким!

Идеально для уличной фотографии и пейзажей.

### Боке — эстетика размытия

**Боке** (от японского ボケ — «размытость») — это характер размытия в нерезких областях.

Объектив X100VI имеет **9 скруглённых лепестков диафрагмы**, что создаёт приятные круглые блики в боке.

```
Хорошее боке:          Плохое боке:

    ○  ○  ○  ○           ⬡  ⬡  ⬡  ⬡
  ○  ○  ○  ○  ○        ⬡  ⬡  ⬡  ⬡  ⬡
    ○  ○  ○  ○           ⬡  ⬡  ⬡  ⬡

Мягкие, круглые        Угловатые,
пятна света           с резкими краями
```

### Как добиться красивого размытия фона

1. **Максимально открытая диафрагма**: f/2
2. **Близко к объекту**: 1-2 метра
3. **Объект далеко от фона**: чем дальше фон, тем сильнее размытие
4. **Яркие точки на фоне**: превращаются в красивые круги

```
❌ Неправильно:              ✅ Правильно:

  👤──────🏠                  👤──────────────────🏠
  1м     1м                   1м               10м

  Фон близко к объекту       Фон далеко от объекта
  = слабое размытие          = сильное размытие
```

   - Близко к объекту (1м)
   - Средняя дистанция (3м)

3. Почувствуйте «характер» 35mm

### Задание 2: Эксперимент с ГРИП

1. Найдите ряд одинаковых объектов (забор, ряд бутылок)
2. Сфокусируйтесь на среднем объекте
3. Снимите на диафрагмах: f/2, f/4, f/8, f/16
4. Сравните, сколько объектов в резкости на каждой диафрагме

### Задание 3: Портрет с боке

1. Найдите модель (или любой объект)
2. Расположите фон минимум в 5 метрах позади
3. Установите f/2
4. Сфокусируйтесь на глазах
5. Оцените качество размытия фона

### Задание 4: Заполняющая вспышка

1. В солнечный день найдите человека против света
2. Снимите без вспышки (лицо в тени)
3. Включите вспышку, уменьшите мощность на -1 EV
4. Снимите с заполняющей вспышкой
5. Сравните результаты

### Задание 5: Зонная фокусировка с ГРИП

1. Переключитесь в ручной фокус
2. Установите f/8
3. Сфокусируйтесь на 4 метра (гиперфокальное)
4. Выйдите на улицу
5. Снимайте без наведения — всё от 2м до ∞ должно быть резким!

## Частые вопросы

### «Могу ли я снимать портреты на X100VI?»

Да! 35mm — не идеальное портретное фокусное, но:
- Подходит для экологических портретов (человек + окружение)
- На f/2 с близкого расстояния даёт хорошее размытие
- Цифровой телеконвертер x1.4 превращает в 50mm

### «Почему на f/16 фото менее резкое, чем на f/8?»

Это **дифракция** — на очень закрытых диафрагмах свет начинает огибать лепестки, размывая изображение. Оптимальная резкость для X100VI — f/5.6-8.

### «Нужна ли мне внешняя вспышка?»

Встроенная вспышка справляется с базовыми задачами. Внешняя нужна для:
- Отражённого света (поворотная головка)
- Большей мощности
- Удалённого управления (стробизм)

### «Как снимать в очень низком свете без вспышки?»

На X100VI:
1. Откройте диафрагму на f/2
2. Используйте стабилизацию (IBIS) — можно снимать до 1/8с
3. Увеличьте ISO до 6400-12800
4. Используйте опору (стена, стол)
