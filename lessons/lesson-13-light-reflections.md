# Занятие №13. Световые схемы. Отражения и рефлексы

## Введение

Фотография буквально означает «рисование светом» (от греч. φῶς — свет и γράφω — пишу). Свет — это главный инструмент фотографа, важнее любой камеры и объектива.

В этом занятии мы научимся понимать свет, использовать простые световые схемы и находить красоту в отражениях и рефлексах вокруг нас.

## Часть I. Световые схемы

### Основные характеристики света

#### 1. Направление света

```
Фронтальный:        Боковой:           Контровой:
    💡                 💡                    │
     │                  ╲                    │
     ▼                   ╲                  💡
    👤                   👤                  │
                                            ▼
                                           👤

Плоский,            Объёмный,           Силуэт,
без теней           текстурный          драматичный
```

#### 2. Жёсткость света

```
Жёсткий свет (солнце, вспышка):    Мягкий свет (облака, софтбокс):

         💡                              ☁️ ☁️ ☁️
          │                                 │
          ▼                                 ▼
    ┌─────────┐                       ┌─────────┐
    │    │░░░░│                       │    │░░░│
    │    │░░░░│                       │    │░░░│
    │    │░░░░│                       │    │░░│
    └─────────┘                       └─────────┘

   Резкие тени,                      Мягкие тени,
   высокий контраст                  плавные переходы
```

**От чего зависит жёсткость:**
- Размер источника **относительно объекта**
- Маленькое солнце = жёсткий свет
- Большое окно рядом = мягкий свет

#### 3. Цветовая температура

| Источник | Температура | Характер |
|----------|-------------|----------|
| Свеча | 1900K | Очень тёплый |
| Лампа накаливания | 2700K | Тёплый |
| Рассвет/закат | 3000-4000K | Тёплый |
| Дневной свет | 5500K | Нейтральный |
| Пасмурно | 6500K | Холодный |
| Тень | 7000K+ | Холодный |

### Базовые световые схемы для портретов

#### 1. Рембрандтовский свет

Назван в честь художника, который часто использовал эту схему.

```
         💡
          ╲
           ╲ 45°
            ╲
        ┌───────┐
        │  ▲    │
        │ 👃    │  ← Треугольник света
        │       │     на затенённой щеке
        └───────┘
           👤
```

**Характеристика:**
- Источник сбоку и сверху (45°)
- На затенённой стороне лица — треугольник света под глазом
- Драматичный, художественный

**Как создать дома:**
- Посадите человека боком к окну
- Пусть повернёт лицо к окну под углом
- Ищите треугольник на щеке

#### 2. Петлевой свет (Loop)

```
         💡
          ╲
           ╲ 30-45°
            ╲
        ┌───────┐
        │ ╭─╮   │
        │ │👃│   │  ← Тень от носа
        │ ╰─╯   │     "петлёй" уходит к щеке
        └───────┘
           👤
```

**Характеристика:**
- Источник сбоку, чуть выше глаз
- Тень от носа направлена вниз и в сторону
- Универсальный, подходит большинству лиц

#### 3. Бабочка (Butterfly / Paramount)

```
            💡
             │
             │
             ▼
        ┌───────┐
        │       │
        │  👃   │  ← Тень под носом
        │  ═    │     как "бабочка"
        └───────┘
           👤
```

**Характеристика:**
- Источник прямо перед лицом, сверху
- Симметричная тень под носом
- Подчёркивает скулы, используется в гламуре

#### 4. Раздельный свет (Split)

```
      💡
       │
       │
       ▼
   ┌───┬───┐
   │░░░│   │
   │░░░│   │  ← Половина лица
   │░░░│   │     в тени
   └───┴───┘
      👤
```

**Характеристика:**
- Источник строго сбоку
- Ровно половина лица освещена
- Очень драматичный, для характерных портретов

### Работа с окном как источником света

Окно — лучший бесплатный источник мягкого света!

```
┌──────────────────────────────────┐
│                                  │
│  ┌─────┐                         │
│  │     │                         │
│  │ ☀️  │────────────▶  👤        │  ← Мягкий боковой свет
│  │     │                         │
│  └─────┘                         │
│   Окно                           │
│                                  │
└──────────────────────────────────┘
```

**Советы:**
- Пасмурный день = огромный софтбокс
- Солнечный день = жёсткий свет (используйте тюль)
- Чем ближе к окну — тем мягче и ярче свет
- Чем дальше — тем контрастнее

### Как сделать отражатель своими руками

Отражатель заполняет тени, уменьшая контраст.

**Простые варианты:**
1. **Белый картон / пенопласт** — мягкое заполнение
2. **Фольга на картоне** — сильное заполнение, жёсткий свет
3. **Серебряный автомобильный экран** — готовый отражатель
4. **Белая футболка / простыня** — для больших поверхностей

```
    💡 (или окно)
     │
     │
     ▼
    👤
     │
     ▲
     │
   ┌───┐
   │░░░│  ← Отражатель возвращает свет
   └───┘     в тени
```

**Как использовать:**
1. Основной свет с одной стороны
2. Отражатель с противоположной
3. Регулируйте расстояние для контроля заполнения

## Часть II. Отражения и рефлексы

### Что такое отражение в фотографии

**Отражение** — это изображение объекта в отражающей поверхности:
- Зеркала
- Вода
- Стёкла
- Металлические поверхности
- Лужи

### Типы отражений

#### 1. Водные отражения

```
┌─────────────────────────────────┐
│         🏔️  🌲  🏠            │  ← Реальный объект
│                                 │
│═════════════════════════════════│  ← Линия воды
│                                 │
│         🏠  🌲  🏔️            │  ← Отражение
│                                 │
└─────────────────────────────────┘
```

**Советы для съёмки:**
- Штиль — чёткое отражение
- Рябь — абстрактное, художественное
- Горизонт по центру для симметрии
- Раннее утро — лучшее время (нет ветра)

#### 2. Отражения в стекле

```
┌─────────────────────────────────┐
│                                 │
│   ┌───────────────────────┐     │
│   │  👤 (отражение)  🏙️   │     │  ← Витрина
│   │      ║         (за    │     │
│   │      ║         стеклом)│     │
│   └───────────────────────┘     │
│                                 │
└─────────────────────────────────┘
```

**Творческие возможности:**
- Двойные экспозиции без обработки
- Слои реальности
- Контекст улицы + объект за стеклом

#### 3. Отражения в лужах

```
┌─────────────────────────────────┐
│    🏢 🏢 🏢                    │
│                                 │
│  ═══════════════════════════    │  ← Лужа
│    🏢 🏢 🏢 (отражение)        │
│                                 │
└─────────────────────────────────┘
```

**Приём:** Снимайте с низкой точки, почти касаясь земли!

### Что такое рефлекс

**Рефлекс** — это отражённый свет, падающий на объект от окружающих поверхностей.

```
    💡
     │
     │
     ▼
    👤────────────┐
     │            │
     │◄───────────│  ← Рефлекс от стены
     │    (свет   │     окрашивает тень
     │  отражается│     в цвет поверхности
     │    обратно)│
              ┌───┘
              │🟥 Красная стена
```

**Примеры рефлексов:**
- Зелёный отсвет на лице от травы
- Тёплый отблеск от кирпичной стены
- Синий оттенок в тенях от неба

### Как использовать рефлексы творчески

#### Цветные рефлексы в портрете

1. Поставьте человека рядом с цветной стеной
2. Одна сторона освещена основным светом
3. Другая получает цветной рефлекс от стены

```
    💡
     │
     ▼
    👤──────🟧  ← Оранжевая стена
        │
        ◄──── Тёплый рефлекс
              на затенённой стороне
```

#### Золотой час и рефлексы

На закате тёплый свет создаёт рефлексы повсюду:
- Стены зданий становятся гигантскими отражателями
- Песок, асфальт — тёплые отражатели
- Всё окрашивается в золотые тона

### Как видеть отражения вокруг

**Тренировка:**
1. Идя по улице, специально ищите отражения
2. Замечайте лужи, витрины, машины
3. Представляйте кадр до того, как поднимете камеру
4. Фотографируйте найденное

**Где искать:**
| Поверхность | Характер отражения |
|-------------|-------------------|
| Лужи | Перевёрнутый мир |
| Витрины | Двойная экспозиция |
| Металл | Искажённые отражения |
| Солнечные очки | Мини-пейзаж в портрете |
| Глаза | Отражение того, на что смотрит человек |
| Мокрый асфальт | Размытые огни |

## Практическое задание

### Задание 1: Портрет у окна

1. Посадите человека боком к окну
2. Добейтесь рембрандтовского треугольника на щеке
3. Добавьте отражатель (белый лист) с теневой стороны
4. Сравните кадры с отражателем и без

### Задание 2: Самодельный отражатель

1. Сделайте отражатель из картона и фольги
2. Снимите портрет:
   - Без отражателя
   - С белым отражателем
   - С серебряным (фольга) отражателем
3. Сравните заполнение теней

### Задание 3: Охота за отражениями

1. Выйдите на улицу после дождя (или найдите лужу)
2. Снимите минимум 10 кадров с отражениями в лужах
3. Экспериментируйте с точкой съёмки

### Задание 4: Витрины

1. Найдите интересную витрину магазина
2. Снимите:
   - Объект за стеклом
   - Отражение улицы в стекле
   - Комбинацию (двойную экспозицию)

### Задание 5: Рефлексы

1. Найдите цветную стену (красная, жёлтая, синяя)
2. Поставьте человека рядом
3. Снимите портрет, показывая цветной рефлекс на коже

## Частые вопросы

### «Нужны ли мне профессиональные осветительные приборы?»

Для начала — нет! Окно + отражатель дают прекрасный результат. Профессиональный свет нужен для:
- Контроля (не зависеть от погоды)
- Повторяемости результата
- Специфических задач

### «Как снимать в помещении без вспышки?»

1. Найдите большое окно
2. Поднимите ISO
3. Откройте диафрагму
4. Используйте стабилизацию X100VI (до 1/8с)
5. Ищите места с хорошим светом

### «Почему мои фото с окном слишком контрастные?»

Слишком большая разница между светом и тенью. Решения:
1. Добавьте отражатель в тени
2. Отодвиньте объект от окна
3. Используйте тюль как диффузор
4. Снимайте в пасмурный день

## Напутствие

Поздравляю! Вы прошли полный курс основ фотографии с Fujifilm X100VI.

Но помните: этот курс — только начало. Фотография — это навык, который развивается всю жизнь.

**Что делать дальше:**

1. **Снимайте каждый день** — даже 10 минут в день дают результат
2. **Анализируйте** свои и чужие работы
3. **Экспериментируйте** — пробуйте новое
4. **Показывайте** свои работы, получайте обратную связь
5. **Получайте удовольствие** — это главное!

> «Камера — это инструмент, который учит людей видеть без камеры» — Доротея Ланг

Ваш X100VI — прекрасный компаньон для этого путешествия. Носите его с собой, снимайте то, что вас трогает, и помните: лучшая камера — та, которая с вами.
