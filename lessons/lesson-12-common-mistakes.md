# Занятие №12. Самые распространённые ошибки начинающих фотографов

> 🎯 **Цель занятия**: Изучить типичные ошибки новичков, понять их причины и научиться их избегать.

---

## Введение

За годы преподавания я видел тысячи фотографий от начинающих. И знаете что? Ошибки у всех одинаковые! Это хорошая новость — значит, их можно систематизировать и избежать.

В этом уроке мы разберём «грабли», на которые наступает каждый новичок, и я покажу, как их обойти. Не расстраивайтесь, если узнаете себя — мы все через это проходили!

## Технические ошибки

### 1. Шевелёнка (размытие от движения камеры)

**Что происходит:**
Фото получается размытым, хотя камера была в фокусе.

```
❌ Шевелёнка:                ✅ Резко:

┌─────────────────┐         ┌─────────────────┐
│  ~~~~~~~~~~~    │         │      🏠         │
│  ~~~~~~~~~~~~   │         │    ────         │
│   ~~~~~~~~~~    │         │   │    │        │
└─────────────────┘         └─────────────────┘
```

**Причина:**
- Слишком длинная выдержка для съёмки с рук
- Дрожание рук при нажатии кнопки

**Как избежать:**
1. Следите за выдержкой: минимум **1/60** для X100VI (благодаря стабилизации)
2. Используйте правильную позу — прижмите локти к телу
3. Натяните ремень для дополнительной опоры
4. Увеличьте ISO вместо длинной выдержки
5. Нажимайте кнопку спуска плавно, не «дёргайте»

**Настройка Auto ISO для борьбы с шевелёнкой:**
`MENU → Настройка съёмки → Настройка ISO → Авто`
- Минимальная выдержка: **1/60**
- Максимальное ISO: **6400**

---

### 2. Промах фокуса

**Что происходит:**
Резкость не там, где нужно — на фоне вместо объекта, на носу вместо глаз.

```
❌ Фокус на фоне:           ✅ Фокус на объекте:

┌─────────────────┐         ┌─────────────────┐
│      [🏠]       │         │       🏠        │
│   👤            │         │   [👤]          │
│  размыто       │         │   резко         │
└─────────────────┘         └─────────────────┘
```

**Причина:**
- Камера сфокусировалась не на том объекте
- Слишком широкая зона AF
- Перефокусировка при перекомпоновке

**Как избежать:**
1. Используйте **точечный AF** для точного контроля
2. Включите **распознавание лиц/глаз** для портретов
3. Проверяйте, что рамка AF на нужном объекте
4. На открытой диафрагме будьте особенно внимательны — ГРИП маленькая

---

### 3. Пересвет и недосвет

**Что происходит:**
Фото слишком светлое (белое небо, потеря деталей) или тёмное.

```
❌ Пересвет:                ❌ Недосвет:               ✅ Нормально:

┌─────────────────┐        ┌─────────────────┐        ┌─────────────────┐
│ ⬜⬜⬜⬜⬜⬜⬜⬜ │        │ ⬛⬛⬛⬛⬛⬛⬛⬛ │        │ ☁️☁️☁️☁️☁️☁️  │
│ ⬜⬜⬜⬜⬜⬜⬜⬜ │        │ ⬛⬛⬛⬛⬛⬛⬛⬛ │        │   🏠          │
│  потеря светов │        │  потеря теней  │        │  детали есть   │
└─────────────────┘        └─────────────────┘        └─────────────────┘
```

**Причина:**
- Камера неправильно оценила сцену
- Не использовали экспокоррекцию
- Сложное освещение (контраст)

**Как избежать:**
1. Смотрите на **гистограмму** после съёмки
2. Используйте **экспокоррекцию** (+/- EV)
3. Помните: снег, песок → +1 EV; тёмные сцены → -1 EV
4. Включите «мигание пересветов» в просмотре

**Включить предупреждение о пересветах:**
`MENU → Настройка воспроизведения → Подсветка` → **Вкл.**

---

### 4. Неправильный баланс белого

**Что происходит:**
Фото имеет неестественный оттенок — слишком жёлтое, синее или зелёное.

**Причина:**
- Авто WB не справился
- Неправильный пресет
- Смешанное освещение

**Как избежать:**
1. Снимайте в **RAW** — WB можно исправить позже
2. В сложных условиях используйте **ручной WB**
3. Проверяйте результат на экране камеры
4. При смешанном свете — выберите доминирующий источник

---

### 5. Слишком высокое ISO (шум)

**Что происходит:**
Фото покрыто «зерном», особенно в тёмных областях.

**Причина:**
- Неоправданно высокое ISO
- Съёмка в темноте без вспышки/штатива

**Как избежать:**
1. ISO должно быть **настолько низким, насколько возможно**
2. Сначала — откройте диафрагму, увеличьте выдержку
3. ISO — последний параметр, который повышаете
4. X100VI хорошо справляется до ISO 6400, выше — только при необходимости

> 💡 **Помните:** Лучше шумное фото, чем смазанное! Шум можно убрать при обработке, шевелёнку — нет.

## Композиционные ошибки

### 6. Кривой горизонт

**Что происходит:**
Горизонт «заваливается» влево или вправо.

```
❌ Криво:                   ✅ Ровно:

┌─────────────────┐         ┌─────────────────┐
│        ╱        │         │                 │
│       ╱         │         │─────────────────│
│      ╱          │         │                 │
└─────────────────┘         └─────────────────┘
```

**Причина:**
- Невнимательность при съёмке
- Спешка

**Как избежать:**
1. Включите **сетку** на экране
2. Используйте **электронный уровень**: `MENU → Настройка экрана → Электр. уровень`
3. Выравнивайте по горизонтальным линиям в кадре
4. Можно исправить при обработке, но лучше снять сразу правильно

---

### 7. «Обрезанные» конечности

**Что происходит:**
Обрезаны руки, ноги, часть головы в неудачных местах.

```
❌ Плохая обрезка:          ✅ Хорошая обрезка:

┌─────────────────┐         ┌─────────────────┐
│       👤        │         │                 │
│      /│\        │         │       👤        │
│     / │         │         │      /│\        │
│ ──────┼─────────│         │     / │ \       │
│       │         │         │                 │
└─────────────────┘         └─────────────────┘
   Обрезано по                По середине
   суставам!                  бедра — ОК
```

**Правило:**
Никогда не обрезайте по суставам (колени, локти, запястья, шея).

**Безопасные места для обрезки:**
- Середина бедра
- Середина голени
- Середина предплечья
- Выше плеч (крупный портрет)

---

### 8. Объект сливается с фоном

**Что происходит:**
Главный объект теряется на фоне.

```
❌ Сливается:               ✅ Выделяется:

┌─────────────────┐         ┌─────────────────┐
│ 🌳🌳👤🌳🌳🌳   │         │ ░░░░░░░░░░░░░░░ │
│ 🌳🌳🌳🌳🌳🌳   │         │ ░░░░░👤░░░░░░░ │
│ 🌳🌳🌳🌳🌳🌳   │         │ ░░░░░░░░░░░░░░░ │
└─────────────────┘         └─────────────────┘
   Где человек?               Контраст с фоном
```

**Как избежать:**
1. Ищите **контраст**: светлый объект на тёмном фоне или наоборот
2. Используйте **размытие фона** (открытая диафрагма)
3. **Смените позицию** — иногда шаг в сторону меняет всё
4. Следите за тем, что находится за объектом

---

### 9. «Дерево из головы»

**Что происходит:**
Позади человека торчит столб, ветка, или другой объект.

```
❌ Плохо:                   ✅ Хорошо:

┌─────────────────┐         ┌─────────────────┐
│        │        │         │                 │
│      👤│        │         │       👤    │   │
│        │        │         │            │   │
└─────────────────┘         └─────────────────┘
   Столб «растёт»             Столб сбоку
   из головы
```

**Как избежать:**
1. **Смотрите на фон** перед съёмкой!
2. Переместитесь или попросите модель сдвинуться
3. Размойте фон открытой диафрагмой
4. Развивайте привычку сканировать кадр целиком

---

### 10. Всё в центре

**Что происходит:**
Объект всегда строго по центру, фото выглядят однообразно.

```
❌ Всегда в центре:         ✅ Разнообразие:

┌─────────────────┐         ┌─────────────────┐
│                 │         │         👤      │
│       👤        │         │                 │
│                 │         │                 │
└─────────────────┘         └─────────────────┘
```

**Как избежать:**
1. Используйте **правило третей**
2. Оставляйте **пространство для взгляда** персонажа
3. Центр — осознанный выбор (симметрия), а не привычка

## Психологические ошибки

### 11. «Слишком далеко»

**Что происходит:**
Фотограф боится подойти ближе, объект теряется в кадре.

```
❌ Далеко:                  ✅ Ближе:

┌─────────────────┐         ┌─────────────────┐
│                 │         │                 │
│       .         │         │      ╭──╮       │
│    (человек     │         │      │👤│       │
│     где-то      │         │      │  │       │
│     там)        │         │      ╰──╯       │
└─────────────────┘         └─────────────────┘
```

> «Если ваши фотографии недостаточно хороши, значит вы недостаточно близко» — Роберт Капа

**Как избежать:**
1. Подойдите **физически ближе**
2. Заполните кадр объектом
3. На X100VI 35mm позволяет работать с близкой дистанции

---

### 12. Слишком много в кадре

**Что происходит:**
В кадре много всего, но непонятно, о чём фото.

**Причина:**
- Хочется показать всё
- Нет главного объекта
- Не умеем «вычитать» лишнее

**Как избежать:**
1. Задайте вопрос: **«О чём это фото?»**
2. Всё, что не отвечает — убрать
3. **Упрощайте**: один объект, одна идея
4. Кадрируйте плотнее

---

### 13. Съёмка без идеи

**Что происходит:**
Снимаем всё подряд, «на память», без понимания, зачем.

**Признаки:**
- Тысячи похожих фото
- Ничего не хочется показать
- «Ну, было красиво»

**Как избежать:**
1. Перед съёмкой спросите: **«Что я хочу сказать этим кадром?»**
2. Ищите **историю**, эмоцию, момент
3. Качество важнее количества
4. Лучше 10 осмысленных кадров, чем 1000 «на всякий случай»

---

### 14. Удаление «неудачных» кадров сразу

**Что происходит:**
Смотрим на экран камеры и сразу удаляем фото, которые кажутся плохими.

**Почему это ошибка:**
- Маленький экран не показывает все детали
- Эмоции влияют на оценку
- Некоторые кадры «раскрываются» позже

**Как избежать:**
1. **Не удаляйте в камере** — делайте это на компьютере
2. Дайте фото «отлежаться» день-два
3. Иногда «брак» оказывается лучшим кадром сессии

---

### 15. Сравнение себя с профессионалами

**Что происходит:**
Смотрим на работы опытных фотографов и расстраиваемся, что не получается так же.

**Почему это вредно:**
- Они снимают 10+ лет, вы — месяц
- Вы видите их лучшие 10 кадров из 10000
- За каждым «простым» кадром — годы практики

**Как относиться:**
1. Сравнивайте себя **с собой вчерашним**
2. Изучайте чужие работы **для вдохновения**, не для самобичевания
3. Каждый мастер когда-то был новичком
4. Прогресс — это путь, не точка назначения

## Чек-лист самопроверки перед съёмкой

Перед нажатием кнопки спуска:

- [ ] Горизонт ровный?
- [ ] Фокус на главном объекте?
- [ ] Нет «деревьев из головы»?
- [ ] Объект не обрезан по суставам?
- [ ] Фон не отвлекает?
- [ ] Экспозиция правильная (гистограмма)?
- [ ] Выдержка достаточно короткая?
- [ ] О чём это фото?

## Практическое задание

### Задание 1: Анализ старых фото

1. Откройте свои фотографии за последний месяц
2. Найдите примеры каждой ошибки из урока
3. Подумайте, как бы вы сняли иначе

### Задание 2: Осознанная съёмка

1. Выйдите на съёмку с целью снять **10 кадров**
2. Перед каждым кадром проходите по чек-листу
3. Не снимайте больше 10 — выбирайте тщательно

### Задание 3: Работа над ошибками

1. Выберите свою главную проблему (шевелёнка, горизонт, центрирование...)
2. Посвятите одну съёмку работе именно над ней
3. Снимайте, пока не начнёт получаться автоматически

## Итоги занятия

Ошибки — это часть обучения. Каждый профессионал прошёл через все эти «грабли». Разница в том, что опытные фотографы:
1. Научились замечать ошибки
2. Исправляют их до нажатия кнопки
3. Превратили правильные действия в привычку

Не расстраивайтесь, если видите много своих ошибок — это значит, что вы учитесь! Осознание проблемы — первый шаг к её решению.
