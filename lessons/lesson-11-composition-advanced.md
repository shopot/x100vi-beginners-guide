## Слои и глубина

### Три плана изображения

Сильная фотография часто имеет несколько планов:

```
┌─────────────────────────────────────┐
│   ☁️ ☁️ ☁️     🏔️ 🏔️             │  ← Дальний план (фон)
│                                     │
├─────────────────────────────────────┤
│         🏠        🌳                │  ← Средний план
│                                     │
├─────────────────────────────────────┤
│    🌸              👤              │  ← Передний план
│  🌿 🌿 🌿 🌿 🌿 🌿 🌿 🌿 🌿        │
└─────────────────────────────────────┘
```

### Зачем нужны слои

1. **Глубина** — фото перестаёт быть «плоским»
2. **Контекст** — зритель понимает, где происходит действие
3. **Интерес** — глаз путешествует по кадру
4. **История** — больше элементов = больше информации

### Как создать глубину

#### 1. Передний план
Добавьте что-то близко к камере:
- Цветы, трава, листья
- Перила, ступени
- Размытые силуэты людей

#### 2. Средний план
Здесь обычно главный объект:
- Человек
- Здание
- Предмет интереса

#### 3. Дальний план (фон)
Контекст и атмосфера:
- Небо, горы
- Городской пейзаж
- Размытые огни

### Практический пример

```
Пейзаж без слоёв:              Пейзаж со слоями:

┌─────────────────────┐        ┌─────────────────────┐
│                     │        │      🏔️ 🏔️          │
│                     │        │    ═══════════       │
│       🏔️            │        │  🌲  🏠  🌲         │
│      ═══════        │        │ ════════════════    │
│                     │        │ 🌸        🌿        │
└─────────────────────┘        └─────────────────────┘

   Плоско, скучно              Глубина, интерес
```

## Визуальный вес и баланс

### Что такое визуальный вес

Каждый элемент в кадре имеет «вес» — способность притягивать внимание.

**Что увеличивает визуальный вес:**
- Размер (большое тяжелее маленького)
- Яркость (светлое привлекает больше)
- Контраст (контрастное выделяется)
- Насыщенность цвета (красный тяжелее серого)
- Резкость (резкое привлекает)
- Положение (объекты наверху кажутся тяжелее)
- Лица и глаза (всегда притягивают)

### Визуальный баланс

```
Сбалансированный кадр:         Несбалансированный:

┌─────────────────────┐        ┌─────────────────────┐
│                     │        │ 🔴                  │
│  🔴           ⚫⚫  │        │ 🔴                  │
│                     │        │ 🔴                  │
│    Большой    Два   │        │                     │
│    объект  = мелких │        │      Пусто          │
└─────────────────────┘        └─────────────────────┘
```

### Типы баланса

#### 1. Симметричный (формальный)
```
┌──────────┬──────────┐
│    🏛️    │    🏛️    │
│    ⬜    │    ⬜    │
│    ⬜    │    ⬜    │
└──────────┴──────────┘
```
- Стабильность, порядок
- Официальность
- Иногда — скука

#### 2. Асимметричный (неформальный)
```
┌─────────────────────┐
│  🔴                 │
│                     │
│              ⚫ ⚫  │
│                 ⚫  │
└─────────────────────┘
```
- Динамика
- Интерес
- Визуальное напряжение

#### 3. Радиальный
```
┌─────────────────────┐
│        ╲│╱         │
│       ──●──        │
│        ╱│╲         │
└─────────────────────┘
```
- Фокус на центре
- Энергия, движение
- Колёса, цветы, архитектура

### Как достичь баланса

| Элемент | Можно уравновесить |
|---------|-------------------|
| Большой объект | Несколько маленьких |
| Яркий цвет | Большая нейтральная область |
| Человек | Архитектурный элемент |
| Резкий объект | Размытое пространство |

## Ракурсы и точка съёмки

### Высота камеры

```
Верхний ракурс (сверху вниз):
         📷
          │
          ▼
         👤

• Уменьшает объект
• Показывает контекст
• Может выглядеть снисходительно

────────────────────────

Уровень глаз (нейтральный):

    📷 ──── 👤

• Естественный взгляд
• Нейтральный
• Не добавляет драмы

────────────────────────

Нижний ракурс (снизу вверх):
         👤
          ▲
          │
         📷

• Увеличивает, возвеличивает
• Добавляет драмы
• Показывает силу, мощь
```

### Практические советы по ракурсам

#### Дети и животные
Снимайте с **их уровня глаз** — присядьте или лягте!

```
❌ Сверху:              ✅ На уровне:

       📷
        │                 📷 ──── 🐕
        ▼
       🐕
```

#### Архитектура
**Низкий ракурс** делает здания величественными:

```
┌───────────────────────┐
│         🏢            │
│        ╱  ╲           │
│       ╱    ╲          │
│      ╱      ╲         │
│     ╱   📷   ╲        │
└─────────────────────────┘
```

#### Еда (Food Photography)
**Угол 45° или строго сверху** — классика:

```
  45 градусов:            Сверху (flat lay):

      📷                      📷
       ╲                       │
        ╲                      ▼
         🍽️                    🍽️
```

### Дистанция съёмки

```
Общий план:              Средний план:            Крупный план:

┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│                 │     │                 │     │                 │
│    🏠  👤  🌳   │     │    ╭─────╮      │     │      ╭───╮      │
│   ════════════  │     │   ╱       ╲     │     │     │ 👁 │      │
│                 │     │  │   👤    │    │     │     │   │      │
│  Контекст       │     │   ╲       ╱     │     │      ╰───╯      │
│                 │     │    ╰─────╯      │     │                 │
└─────────────────┘     └─────────────────┘     └─────────────────┘
   История                 Персонаж               Эмоция
```

## Цвет в композиции

### Цветовой круг

```
           Жёлтый
              │
    Оранжевый─┼─Зелёный
             │
    Красный──┼──Голубой
             │
    Пурпурный─┼─Синий
```

### Цветовые схемы

#### 1. Комплементарные (дополнительные)
Противоположные на круге:
- Синий + Оранжевый
- Красный + Зелёный
- Жёлтый + Фиолетовый

```
Пример: закат на фоне синего неба

┌─────────────────────────┐
│  🔵🔵🔵🔵🔵🔵🔵🔵🔵  │
│  🔵🔵🔵🔵🔵🔵🔵🔵🔵  │
│  🟠🟠🟠🟠🟠🟠🟠🟠🟠  │
│  🟠🟠🟠🟠🟠🟠🟠🟠🟠  │
└─────────────────────────┘
```

**Эффект:** Контраст, энергия, драма

#### 2. Аналоговые (соседние)
Рядом на круге:
- Синий + Голубой + Зелёный
- Оранжевый + Жёлтый + Красный

```
Пример: осенний лес

┌─────────────────────────┐
│  🟤🟠🟡🟤🟠🟡🟤🟠🟡  │
│  🟡🟤🟠🟡🟤🟠🟡🟤🟠  │
│  🟠🟡🟤🟠🟡🟤🟠🟡🟤  │
└─────────────────────────┘
```

**Эффект:** Гармония, спокойствие

#### 3. Монохромный
Оттенки одного цвета:

```
Пример: туман

┌─────────────────────────┐
│  ⬜⬜⬜⬜⬜⬜⬜⬜⬜  │
│  🔘🔘🔘🔘🔘🔘🔘🔘🔘  │
│  ⚫⚫⚫⚫⚫⚫⚫⚫⚫  │
└─────────────────────────┘
```

**Эффект:** Элегантность, настроение

### Цветовой акцент

Один яркий цвет на нейтральном фоне:

```
┌─────────────────────────┐
│  ⬜⬜⬜⬜⬜⬜⬜⬜⬜  │
│  ⬜⬜⬜⬜🔴⬜⬜⬜⬜  │  ← Красный зонтик
│  ⬜⬜⬜⬜⬜⬜⬜⬜⬜  │     на сером фоне
│  ⬜⬜⬜⬜⬜⬜⬜⬜⬜  │
└─────────────────────────┘
```

**Совет:** На X100VI используйте симуляции плёнки для контроля цвета:
- **Classic Chrome** — приглушённые цвета
- **Velvia** — насыщенные цвета
- **Acros** — чёрно-белый, когда цвет отвлекает

## Когда нарушать правила

### Зачем нарушать правила

> «Изучи правила как профессионал, чтобы нарушать их как художник» — Пикассо

Нарушение правил может:
- Создать напряжение
- Передать эмоцию
- Выделить вас среди других
- Рассказать историю нестандартно

### Примеры осознанного нарушения

#### 1. Объект в центре
Вместо правила третей:

```
┌─────────────────────────┐
│                         │
│                         │
│           👁            │  ← Глаз точно в центре
│                         │     = интенсивность, конфронтация
│                         │
└─────────────────────────┘
```

**Когда работает:** Симметрия, прямой взгляд, минимализм

#### 2. Наклонённый горизонт
Вместо ровного:

```
┌─────────────────────────┐
│         ╱               │
│        ╱                │
│       ╱     👤          │  ← Динамика, нестабильность
│      ╱                  │
│     ╱                   │
└─────────────────────────┘
```

**Когда работает:** Экшн, напряжение, дезориентация

#### 3. Обрезка «неправильно»
Обрезать часть объекта:

```
┌─────────────────────────┐
│                         │
│  ─────                  │
│  │    │                 │
│  │ 👤 │                 │  ← Обрезанная фигура
│  │    │                 │     = загадка, напряжение
│──┘                      │
└─────────────────────────┘
```

**Когда работает:** Тайна, тесное пространство, акцент на детали

#### 4. Много негативного пространства
«Слишком много» пустоты:

```
┌─────────────────────────────────────┐
│                                     │
│                                     │
│                                     │
│                                     │
│                              👤     │  ← Одиночество, масштаб
│                                     │
└─────────────────────────────────────┘
```

**Когда работает:** Одиночество, величие природы, минимализм

### Как понять, работает ли нарушение

Спросите себя:
1. **Есть ли цель?** Нарушение должно что-то говорить
2. **Это осознанно?** Случайность vs намерение
3. **Усиливает ли это историю?** Нарушение должно помогать, не мешать
4. **Как реагирует зритель?** Покажите другим, узнайте мнение

## Практическое задание

### Задание 1: Три плана

1. Найдите локацию с глубиной (парк, улица с перспективой)
2. Снимите, включив в кадр:
   - Передний план (что-то близко)
   - Средний план (главный объект)
   - Дальний план (фон)
3. Сравните с фото без переднего плана

### Задание 2: Баланс

1. Снимите асимметричный, но сбалансированный кадр
2. Используйте один большой объект и несколько маленьких
3. Или яркий объект и нейтральное пространство

### Задание 3: Ракурсы

1. Выберите объект (человек, здание, предмет)
2. Снимите с трёх ракурсов:
   - Сверху
   - На уровне
   - Снизу
3. Сравните, как меняется восприятие

### Задание 4: Цветовая схема

1. Найдите сцену с комплементарными цветами (синий + оранжевый на закате)
2. Найдите сцену с аналоговыми цветами (осенняя листва)
3. Создайте фото с цветовым акцентом

### Задание 5: Нарушение правил

1. Осознанно нарушьте правило третей — поместите объект в центр
2. Наклоните горизонт для эффекта
3. Оставьте «слишком много» пустого пространства
4. Оцените, работает ли это

## Итоги двух занятий по композиции

### Правила, которые вы изучили:

| Правило | Суть | Эффект |
|---------|------|--------|
| Правило третей | Объект на пересечениях | Динамика |
| Золотое сечение | Пропорция 1:1.618 | Гармония |
| Ведущие линии | Линии к объекту | Направление |
| Обрамление | Рамка внутри кадра | Фокус |
| Симметрия | Зеркальность | Порядок |
| Паттерны | Повторение | Ритм |
| Негативное пространство | «Пустота» | Акцент |
| Слои | Передний/средний/дальний план | Глубина |
| Баланс | Распределение веса | Гармония |
| Цвет | Схемы и акценты | Эмоция |

### Главное

Композиция — это не список правил, которые нужно выполнять. Это **инструменты**, которые помогают рассказать историю. Изучите их, практикуйте, а затем — доверяйте интуиции.

> «Правила композиции — как правила грамматики. Они помогают общаться, но великая литература иногда их нарушает.»
