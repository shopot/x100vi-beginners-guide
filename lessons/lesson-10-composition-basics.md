# Занятие №10. Основы композиции (начало)

> 🎯 **Цель занятия**: Освоить базовые правила композиции, понять назначение сетки на экране камеры и научиться делать фотографии, которые притягивают взгляд.

---

## Введение

Вы можете идеально настроить экспозицию, добиться идеальной резкости и правильного баланса белого — но если композиция слабая, снимок не будет «работать». Композиция — это язык, на котором фотограф разговаривает со зрителем.

В этом и следующем уроках мы изучим законы, которые делают изображение гармоничным, и научимся их применять (а иногда — осознанно нарушать).

---

## Что такое композиция

**Композиция** (от лат. compositio — составление, связывание) — это:
- Расположение элементов в кадре
- Способ направить взгляд зрителя
- Инструмент передачи идеи и эмоции

### Почему композиция важна

```
Техническая правильность          Эмоциональное воздействие
         │                                 │
         ▼                                 ▼
    Экспозиция ─────────┐     ┌───────── Композиция
    Фокус ──────────────┼─────┼───────── Момент
    Баланс белого ──────┘     └───────── История

         Фото = Техника + Творчество
```

Без хорошей композиции даже технически безупречный снимок будет скучным.

## Сетка на экране камеры

### Что это за линии

На экране и в видоискателе X100VI можно включить направляющую сетку:

```
┌───────┬───────┬───────┐
│       │       │       │
│   ×   │       │   ×   │
│       │       │       │
├───────┼───────┼───────┤
│       │       │       │
│       │       │       │
│       │       │       │
├───────┼───────┼───────┤
│       │       │       │
│   ×   │       │   ×   │
│       │       │       │
└───────┴───────┴───────┘

× — точки силы (пересечения линий)
```

**Как включить:**
`MENU → Настройка экрана → Направляющая кадра`

**Варианты:**
- **Сетка 3×3** — для правила третей
- **Сетка 6×4** — более детальная
- **HD Кадрир.** — соотношение 16:9

### Зачем нужна сетка

1. **Правило третей** — размещение объектов на линиях и пересечениях
2. **Выравнивание горизонта** — горизонт по линии
3. **Симметрия** — центральная линия для симметричных сюжетов
4. **Баланс** — распределение визуального веса

## Правило третей

### Суть правила

Разделите кадр на 9 равных частей двумя горизонтальными и двумя вертикальными линиями. **Размещайте важные элементы на линиях или их пересечениях.**

```
┌───────┬───────┬───────┐
│       │       │       │
│       │   👁   │       │  ← Глаза портрета на верхней линии
│       │       │       │
├───────┼───────┼───────┤
│       │       │       │
│       │  👤   │       │  ← Человек на правой трети
│       │       │       │
├───────┼───────┼───────┤
│ 🌊🌊🌊│🌊🌊🌊 │🌊🌊🌊 │  ← Горизонт на нижней линии
│       │       │       │
│       │       │       │
└───────┴───────┴───────┘
```

### Почему это работает

Человеческий глаз естественно притягивается к точкам на пересечениях, а не к центру. Это создаёт:
- Динамику
- Напряжение
- Визуальный интерес

### Примеры применения

#### Портрет

```
┌───────┬───────┬───────┐
│       │       │       │
│       │   👁━━━━━━━▶  │  ← Глаза на верхней трети
│       │       │       │     Взгляд направлен в "пустое" пространство
├───────┼───────┼───────┤
│       │       │       │
│       │       │       │
│       │       │       │
├───────┼───────┼───────┤
│       │       │       │
│       │       │       │
│       │       │       │
└───────┴───────┴───────┘
```

#### Пейзаж

```
┌───────┬───────┬───────┐
│  ☁️   │  ☁️   │  ☁️   │
│       │       │       │  ← Небо занимает 1/3
│       │       │       │
├───────┼───────┼───────┤
│───────│───────│───────│  ← Горизонт
│  🌳   │       │  🏠   │
│       │       │       │  ← Земля занимает 2/3
├───────┼───────┼───────┤
│       │       │       │
│       │  🌷   │       │  ← Объект на пересечении
│       │       │       │
└───────┴───────┴───────┘
```

### Когда НЕ использовать правило третей

- Симметричные объекты (архитектура, отражения)
- Когда центр — часть идеи
- Для создания напряжения через нарушение ожиданий

## Золотое сечение

### Что это такое

**Золотое сечение** — это пропорция, которую люди воспринимают как гармоничную: примерно 1:1.618.

```
                    1.618
        ├────────────────────────┤

┌───────────────────┬────────────┐
│                   │            │
│         A         │     B      │
│                   │            │
└───────────────────┴────────────┘
        A ÷ B = 1.618
```

### Спираль Фибоначчи

На основе золотого сечения строится спираль, которая направляет взгляд:

```
┌─────────────────────────────┐
│                        ╭──╮ │
│                       ╱    │ │
│                      │     │ │
│    ╭────────────────╮╯     │ │
│   ╱                        │ │
│  │                         │ │
│  │         👁 ←────────────╯ │  ← Объект в фокусной точке спирали
│   ╲                          │
│    ╰─────────────────────────│
└──────────────────────────────┘
```

### Правило третей vs Золотое сечение

```
Правило третей:              Золотое сечение:

┌───┬───┬───┐                ┌──────┬────┐
│   │   │   │                │      │    │
├───┼───┼───┤                │      │    │
│   │   │   │                ├──────┼────┤
├───┼───┼───┤                │      │    │
│   │   │   │                │      │    │
└───┴───┴───┘                └──────┴────┘

33% │ 33% │ 33%              38% │ 62%
```

Золотое сечение даёт более асимметричное, часто более динамичное разделение.

## Ведущие линии

### Что это такое

**Ведущие линии** — это линии в кадре, которые направляют взгляд зрителя к главному объекту.

```
┌───────────────────────────────┐
│                               │
│               ⭐              │  ← Точка интереса
│              ╱                │
│             ╱                 │
│            ╱                  │  ← Взгляд следует по линии
│           ╱                   │
│          ╱                    │
│ ─────────                     │  ← Линия "ведёт" в кадр
└───────────────────────────────┘
```

### Типы ведущих линий

#### Прямые линии

```
Горизонтальные:          Вертикальные:          Диагональные:
   спокойствие             стабильность            динамика

────────────────         │ │ │ │ │ │              ╲   ╱
────────────────         │ │ │ │ │ │               ╲ ╱
────────────────         │ │ │ │ │ │                ╳
                                                   ╱ ╲
                                                  ╱   ╲
```

#### Сходящиеся линии (перспектива)

```
┌───────────────────────────────┐
│             · ·               │  ← Точка схода
│            ·   ·              │
│           ·     ·             │
│          ·       ·            │
│         ·         ·           │
│        ·           ·          │
│       ·             ·         │
│ ─────·───────────────·─────── │  ← Линии сходятся
└───────────────────────────────┘
```

### Примеры ведущих линий

| Объект | Эффект |
|--------|--------|
| Дорога, рельсы | Глубина, путешествие |
| Река | Плавность, движение |
| Забор, ограда | Ритм, направление |
| Тени | Графичность |
| Архитектурные линии | Структура |
| Взгляд человека | Невидимая линия к объекту внимания |

### Практический совет

> 💡 Ведущие линии работают лучше всего, когда начинаются от края кадра (особенно от нижнего угла) и ведут к главному объекту.

## Обрамление (Frame within frame)

### Концепция

Используйте элементы сцены, чтобы создать «рамку» вокруг главного объекта.

```
┌─────────────────────────────────┐
│ ╔═══════════════════════════╗   │
│ ║                           ║   │
│ ║    ┌─────────────────┐    ║   │  ← Арка, дверной проём
│ ║    │                 │    ║   │
│ ║    │       👤        │    ║   │  ← Объект внутри "рамки"
│ ║    │                 │    ║   │
│ ║    └─────────────────┘    ║   │
│ ║                           ║   │
│ ╚═══════════════════════════╝   │
└─────────────────────────────────┘
```

### Примеры обрамления

- Арки и дверные проёмы
- Окна
- Ветви деревьев
- Тоннели
- Руки, образующие сердечко
- Архитектурные элементы

### Зачем это нужно

1. **Фокусирует внимание** на главном объекте
2. **Добавляет глубину** — несколько планов
3. **Создаёт контекст** — где происходит действие
4. **Закрывает отвлекающие элементы** по краям

## Симметрия и паттерны

### Симметрия

```
Вертикальная симметрия:      Горизонтальная (отражение):

┌─────────┬─────────┐        ┌───────────────────┐
│    🏛️    │    🏛️    │        │      🏔️🏔️🏔️       │
│   ╱│╲   │   ╱│╲   │        │                   │
│  ╱ │ ╲  │  ╱ │ ╲  │        │═══════════════════│  ← Вода
│    │    │    │    │        │      🏔️🏔️🏔️       │  ← Отражение
│    │    │    │    │        │                   │
└─────────┴─────────┘        └───────────────────┘
```

**Когда использовать:**
- Архитектура
- Отражения в воде
- Формальные портреты
- Для передачи стабильности, порядка

**Важно:** При симметрии размещайте центральную линию точно по центру!

### Паттерны (ритм)

Повторяющиеся элементы создают визуальный ритм:

```
┌───────────────────────────────────┐
│  ⬜  ⬜  ⬜  ⬜  ⬜  ⬜  ⬜  ⬜  ⬜ │
│  ⬜  ⬜  ⬜  ⬜  ⬜  ⬜  ⬜  ⬜  ⬜ │
│  ⬜  ⬜  ⬜  ⬜  🟥  ⬜  ⬜  ⬜  ⬜ │  ← Нарушение паттерна!
│  ⬜  ⬜  ⬜  ⬜  ⬜  ⬜  ⬜  ⬜  ⬜ │
│  ⬜  ⬜  ⬜  ⬜  ⬜  ⬜  ⬜  ⬜  ⬜ │
└───────────────────────────────────┘
```

**Приём:** Найдите паттерн и нарушьте его одним элементом — это мгновенно привлекает внимание!

## Негативное пространство

### Что это такое

**Негативное пространство** (negative space) — это «пустое» пространство вокруг главного объекта.

```
┌───────────────────────────────────┐
│                                   │
│                                   │
│                                   │  ← Негативное пространство
│                                   │     (пустота)
│                                   │
│                        🦅          │  ← Объект
│                                   │
└───────────────────────────────────┘
```

### Зачем нужно негативное пространство

1. **Выделяет объект** — нет конкуренции за внимание
2. **Создаёт атмосферу** — одиночество, свобода, минимализм
3. **Даёт «воздух»** — кадр не перегружен
4. **Направляет взгляд** — некуда больше смотреть

### Правило направления взгляда

Если объект (человек, животное) смотрит в определённую сторону, оставьте пространство перед ним:

```
✅ Правильно:                    ❌ Неправильно:

┌─────────────────────┐          ┌─────────────────────┐
│                     │          │                     │
│  👤━━━▶            │          │            ◀━━━👤  │
│                     │          │                     │
│  Пространство       │          │  Объект упирается   │
│  перед взглядом     │          │  в край кадра       │
└─────────────────────┘          └─────────────────────┘
```

То же касается движущихся объектов — оставляйте пространство по направлению движения.

## Частые вопросы

### «Нужно ли всегда следовать правилам?»

Нет! Правила — это инструменты, а не законы. Изучите их, чтобы:
1. Понимать, почему некоторые снимки «работают»
2. Иметь инструменты для улучшения кадра
3. Осознанно нарушать их для эффекта

### «Как научиться видеть композицию?»

1. **Анализируйте чужие работы** — почему этот снимок привлекает?
2. **Снимайте много** — композиция развивается с практикой
3. **Смотрите на мир без камеры** — ищите кадры глазами
4. **Делайте несколько вариантов** — потом сравните, какой лучше

### «Должен ли горизонт быть на линии трети?»

Зависит от сюжета:
- **Интересное небо** (облака, закат) — горизонт на нижней трети
- **Интересный передний план** — горизонт на верхней трети
- **Отражение** — горизонт по центру
