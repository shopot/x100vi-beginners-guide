## Часть I. RAW и JPEG — что выбрать?

### Что такое JPEG

**JPEG (Joint Photographic Experts Group)** — это формат изображения со сжатием.

**Что происходит при создании JPEG:**

```
Свет → Матрица → Сырые данные → Обработка камеры → Сжатие → JPEG файл
                                      ↓
                              • Баланс белого
                              • Симуляция плёнки
                              • Резкость
                              • Шумоподавление
                              • Цветовой профиль
```

**Характеристики JPEG:**
- Размер файла: 5-15 МБ
- Готов к использованию сразу
- Камера «запекла» все настройки
- 8 бит на канал (16.7 млн цветов)

### Что такое RAW

**RAW** — это «сырые» данные прямо с матрицы, без обработки.

**Что происходит при создании RAW:**

```
Свет → Матрица → Сырые данные → Минимальная упаковка → RAF файл (RAW)
                                      ↓
                              • Сохраняется ВСЁ
                              • Никакой обработки
                              • Метаданные о настройках
```

**Характеристики RAW (RAF для Fujifilm):**
- Размер файла: 40-70 МБ
- Требует обработки в программе
- Все настройки можно изменить
- 14 бит на канал (4+ триллиона цветов)

### Визуальная аналогия

**JPEG** — это готовый отпечаток из фотолаборатории:
- Удобный, красивый
- Но если хотите изменить — нужно заново печатать (с потерями)

**RAW** — это цифровой негатив:
- Требует «проявки»
- Но даёт полный контроль над результатом

### Сравнение форматов

| Параметр | JPEG | RAW |
|----------|------|-----|
| Размер файла | 5-15 МБ | 40-70 МБ |
| Разрядность | 8 бит | 14 бит |
| Готовность | Сразу | Требует обработки |
| Изменение WB | Ограничено | Полное |
| Восстановление светов | Минимально | До 2 ступеней |
| Восстановление теней | Минимально | До 3 ступеней |
| Симуляция плёнки | Запечена | Применяется при конвертации |
| Скорость обработки | Мгновенно | Время на конвертацию |

### Особенность Fujifilm X100VI

> 💡 **Важно**: JPEG из камер Fujifilm — одни из лучших в индустрии!

Благодаря:
- Процессору X-Processor 5
- 20+ симуляциям плёнки
- Тонкой настройке цвета

Многие профессионалы снимают на Fujifilm только в JPEG и получают отличные результаты.

### Когда что использовать

#### Только JPEG:
- Повседневная съёмка
- Когда важна скорость (путешествия, репортаж)
- Когда JPEG из камеры вас устраивает
- При ограниченном месте на карте

#### Только RAW:
- Коммерческая съёмка
- Сложные световые условия
- Когда нужна максимальная гибкость
- Для глубокой ретуши

#### RAW + JPEG (рекомендую!)
- JPEG для быстрого просмотра и публикации
- RAW как страховка и для особых кадров
- Лучшее из двух миров

**Настройка на X100VI:**
`MENU → Качество изобр. → Качество изображения → RAW + Fine`

## Часть III. Цветовое пространство

### Что такое цветовое пространство

Цветовое пространство — это диапазон цветов, который может содержать изображение.

### Основные цветовые пространства

#### sRGB

```
          ╱╲
         ╱  ╲
        ╱ sRGB╲
       ╱      ╲
      ╱────────╲
```

- Стандарт для интернета и экранов
- Самый маленький охват
- Гарантированно корректное отображение везде

**Когда использовать:**
- Публикация в интернете
- Отправка по email
- Печать в минилабах

#### Adobe RGB

```
          ╱╲
         ╱  ╲
        ╱    ╲
       ╱ Adobe ╲
      ╱   RGB   ╲
     ╱──────────╲
```

- Шире, чем sRGB
- Больше зелёных и голубых оттенков
- Для профессиональной печати

**Когда использовать:**
- Печать в профессиональных лабораториях
- Работа для полиграфии
- Архивирование

#### ProPhoto RGB

```
          ╱╲
         ╱  ╲
        ╱    ╲
       ╱      ╲
      ╱ ProPhoto╲
     ╱    RGB    ╲
    ╱────────────╲
```

- Самый широкий охват
- Включает цвета за пределами видимого спектра
- Только для профессионального workflow

### Рекомендации для X100VI

**В камере:**
`MENU → Качество изобр. → Цв. простр.` → **sRGB** (для большинства)

**При обработке RAW:**
- Работайте в ProPhoto RGB или Adobe RGB
- При экспорте конвертируйте в sRGB для интернета

## Часть IV. Что такое «слои» и зачем они нужны

### Концепция слоёв

Представьте стопку прозрачных плёнок, лежащих друг на друге:

```
     ┌─────────────────┐  ← Слой 3: Текст
     │    ЗАГОЛОВОК    │
     ├─────────────────┤
     │   ┌───────┐     │  ← Слой 2: Объект
     │   │   👤  │     │
     │   └───────┘     │
     ├─────────────────┤
     │ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │  ← Слой 1: Фон
     │ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │
     └─────────────────┘

          Результат:
     ┌─────────────────┐
     │    ЗАГОЛОВОК    │
     │   ┌───────┐     │
     │   │   👤  │     │
     │ ▓▓└───────┘▓▓▓▓ │
     │ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │
     └─────────────────┘
```

### Преимущества работы со слоями

1. **Недеструктивное редактирование**
   - Изменения на одном слое не затрагивают другие
   - Можно вернуться и изменить что угодно

2. **Гибкость**
   - Перемещение, масштабирование элементов независимо
   - Изменение порядка слоёв

3. **Эффекты**
   - Режимы наложения (Multiply, Screen, Overlay...)
   - Прозрачность слоёв

### Панель слоёв в Photoshop

```
┌─────────────────────────────────┐
│ Слои                        × │
├─────────────────────────────────┤
│ Режим: Нормальный ▼  Непр: 100%│
├─────────────────────────────────┤
│ 🔒 Замки: □ □ □ □              │
├─────────────────────────────────┤
│ 👁 Слой 3 "Текст"              │ ← Верхний слой
├─────────────────────────────────┤
│ 👁 Слой 2 "Объект"             │
├─────────────────────────────────┤
│ 👁 🔒 Слой 1 "Фон"              │ ← Фоновый слой
└─────────────────────────────────┘
     │        │
     │        └── Имя слоя
     └───────────── 👁 = видимость слоя
```

### Основные операции со слоями

#### Создание нового слоя
- `Слой → Новый → Слой` или `Ctrl/Cmd + Shift + N`

#### Дублирование слоя
- `Ctrl/Cmd + J` — дублировать выделенную область или весь слой

#### Объединение слоёв
- `Ctrl/Cmd + E` — объединить с предыдущим
- `Ctrl/Cmd + Shift + E` — объединить видимые

#### Изменение порядка
- Перетащите слой мышкой вверх/вниз

### Корректирующие слои

Особый тип слоёв для неразрушающей коррекции:

```
┌─────────────────────────────────┐
│ ○ Уровни                       │ ← Корректирующий слой
├─────────────────────────────────┤
│ 👁 Фотография                   │ ← Исходное изображение
└─────────────────────────────────┘
```

**Преимущества:**
- Не изменяют пиксели исходного изображения
- Можно изменить настройки в любой момент
- Можно отключить/удалить без последствий

**Популярные корректирующие слои:**
- **Яркость/Контрастность** — простая коррекция
- **Уровни** — точная настройка тонов
- **Кривые** — профессиональная коррекция
- **Цветовой тон/Насыщенность** — работа с цветом
- **Чёрно-белое** — конвертация в ч/б

## Часть V. Базовая обработка фотографии

### Workflow обработки

```
1. Импорт RAW → 2. Базовая коррекция → 3. Ретушь → 4. Финальная → 5. Экспорт
                   в конвертере         (если нужна)   коррекция
```

### Шаг 1: Открытие RAW в Camera Raw / Lightroom

При открытии RAF файла в Photoshop автоматически запускается Camera Raw.

### Шаг 2: Базовые коррекции

#### Экспозиция
- Сделать снимок светлее или темнее
- Диапазон: -5 до +5 ступеней

#### Контраст
- Увеличивает разницу между светами и тенями
- Обычно +10...+30 для «объёмности»

#### Света (Highlights)
- Восстановление деталей в ярких областях
- Сдвиг влево (-) возвращает детали в небе, окнах

#### Тени (Shadows)
- Вытягивание деталей из тёмных областей
- Сдвиг вправо (+) проявляет детали в тенях

#### Белые/Чёрные (Whites/Blacks)
- Установка точки белого и чёрного
- Определяет общий диапазон тонов

### Шаг 3: Работа с цветом

#### Температура (Temperature)
- Теплее (вправо, жёлтый) или холоднее (влево, синий)

#### Оттенок (Tint)
- Коррекция зелёного/пурпурного оттенка

#### Насыщенность (Saturation)
- Интенсивность всех цветов
- Осторожно! Легко переборщить

#### Сочность (Vibrance)
- «Умная» насыщенность
- Усиливает слабые цвета, не трогает насыщенные
- Щадит оттенки кожи

### Шаг 4: Резкость и шумоподавление

#### Резкость (Sharpening)
- Amount: степень резкости (50-100 для начала)
- Radius: размер области (0.8-1.2 обычно)
- Detail: детализация (25-50)
- Masking: маска для применения только к контурам

#### Шумоподавление (Noise Reduction)
- Luminance: яркостный шум (точки)
- Color: цветовой шум (цветные точки)

### Шаг 5: Кадрирование

Инструмент «Рамка» (C) позволяет:
- Обрезать лишнее
- Выровнять горизонт
- Изменить соотношение сторон

**Популярные соотношения:**
- 3:2 — стандарт камеры
- 4:3 — для экранов
- 1:1 — квадрат для Instagram
- 16:9 — кинематографичный формат

## Практическое задание

### Задание 1: Сравните RAW и JPEG

1. Снимите одну сцену в режиме RAW+JPEG
2. Откройте оба файла на компьютере
3. Попробуйте сильно изменить экспозицию (+2 EV) в обоих
4. Сравните качество — в каком больше шумов и артефактов?

### Задание 2: Базовая коррекция RAW

1. Откройте RAW-файл в Photoshop (Camera Raw)
2. Выполните коррекцию:
   - Настройте экспозицию
   - Восстановите света и тени
   - Подправьте баланс белого
   - Добавьте немного контраста
3. Сохраните в JPEG с качеством 80%

### Задание 3: Работа со слоями

1. Откройте любое фото в Photoshop
2. Создайте корректирующий слой «Чёрно-белое»
3. Измените его непрозрачность на 50%
4. Получится эффект «приглушённых цветов»
5. Поэкспериментируйте с разной непрозрачностью

### Задание 4: Практика кадрирования

1. Откройте несколько своих фотографий
2. Попробуйте улучшить композицию кадрированием
3. Обрежьте лишнее, выровняйте горизонт
4. Сохраните варианты до и после

## Частые вопросы

### «Нужен ли мне Photoshop?»

Для начала — не обязательно. Можно использовать:
- **Бесплатные:** GIMP, Darktable, Photopea (онлайн)
- **Мобильные:** Lightroom Mobile (бесплатная версия)
- **Встроенные:** Fujifilm X RAW Studio (бесплатный от Fujifilm)

### «RAW файлы занимают много места. Что делать?»

Варианты:
1. Снимать в JPEG, если устраивает качество
2. Купить карту памяти большего объёма
3. Регулярно переносить файлы на компьютер/диск
4. Использовать сжатый RAW (Lossless Compressed)

### «Почему мои RAW выглядят хуже, чем JPEG?»

RAW — это «сырьё». Камера не применяет к нему:
- Симуляцию плёнки
- Резкость
- Шумоподавление
- Коррекцию цвета

Вам нужно сделать это самостоятельно в конвертере. Или использовать профили камеры (Camera Matching Profiles в Lightroom).

### «Какие настройки экспорта использовать для Instagram?»

- Формат: JPEG
- Цветовое пространство: sRGB
- Качество: 80-90%
- Размер: 1080px по короткой стороне (или 1080x1350 для вертикального)
