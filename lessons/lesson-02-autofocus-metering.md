# Занятие №2. Автофокус. Экспозамер и экспопара

> 🎯 **Цель занятия**: Освоить систему автофокуса X100VI, понять принципы экспозамера и научиться быстро настраивать экспозицию в любых условиях.

---

## Введение

Если в первом занятии мы познакомились с «анатомией» камеры, то сегодня мы научимся ей управлять. Автофокус и экспозиция — это два навыка, которые определяют 90% успеха ваших снимков.

X100VI оснащена одной из лучших систем автофокуса среди компактных камер — 425 точек фазовой детекции, распознавание лиц и глаз, отслеживание объектов. Давайте разберёмся, как использовать эту мощь!

---

## Часть I. Автофокус

### Режимы автофокуса на X100VI

Переключатель на передней панели камеры позволяет выбрать один из трёх режимов:

#### S — Single AF (Одиночный автофокус)

**Как работает:**
- Нажимаете кнопку спуска наполовину
- Камера фокусируется и «замирает» на этом расстоянии
- Пока держите кнопку — фокус заблокирован

**Когда использовать:**
- Неподвижные объекты
- Портреты
- Пейзажи
- Натюрморты
- 90% повседневной съёмки

**Преимущество:** Точность и предсказуемость

#### C — Continuous AF (Следящий автофокус)

**Как работает:**
- Камера постоянно отслеживает объект
- Фокус обновляется, пока вы держите кнопку наполовину
- Использует алгоритмы предсказания движения

**Когда использовать:**
- Движущиеся объекты (дети, животные, спорт)
- Уличная фотография в динамике
- Любые непредсказуемые сцены

**Особенность X100VI:** В режиме C доступно отслеживание объекта и распознавание глаз в движении!

#### M — Manual Focus (Ручная фокусировка)

**Как работает:**
- Вы вращаете кольцо фокусировки на объективе
- Камера показывает помощники: пикинг, увеличение, шкалу расстояний

**Когда использовать:**
- Макросъёмка
- Сложные условия (съёмка через стекло, решётку)
- Зонная фокусировка в уличной съёмке
- Когда AF «мечется» и не может определиться

### Типы зон автофокуса

В меню `AF/MF → Режим AF` доступны различные зоны:

#### Точечный (Single Point)

```
┌─────────────────┐
│                 │
│       [■]       │
│                 │
└─────────────────┘
```

- Самая маленькая зона фокусировки
- Максимальная точность
- Идеально для портретов (фокус на глазу)

#### Зона (Zone)

```
┌─────────────────┐
│    ┌─────┐      │
│    │ ■ ■ │      │
│    │ ■ ■ │      │
│    └─────┘      │
└─────────────────┘
```

- Группа точек (размер настраивается)
- Хороший баланс скорости и точности
- Рекомендую для повседневной съёмки

#### Широкая/Отслеживание (Wide/Tracking)

```
┌─────────────────┐
│ ■ ■ ■ ■ ■ ■ ■ ■ │
│ ■ ■ ■ ■ ■ ■ ■ ■ │
│ ■ ■ ■ ■ ■ ■ ■ ■ │
└─────────────────┘
```

- Камера сама выбирает точку
- В режиме C — отслеживает объект
- Удобно для репортажа

#### Распознавание лиц/глаз (Face/Eye Detection)

- Автоматически находит лица в кадре
- Фокусируется на ближайшем глазе
- Можно выбрать приоритет правого или левого глаза

> 💡 **Мой совет**: Для портретов всегда включайте распознавание глаз! Путь: `MENU → AF/MF → Настр. распозн. лиц/глаз`

### Как перемещать точку фокусировки

1. **Джойстиком** — самый быстрый способ
2. **Сенсорным экраном** — касайтесь нужной области
3. **Через Q-меню** — выберите «Область фокусировки»

#### Быстрый сброс точки в центр

Нажмите и удерживайте джойстик (или кнопку DISP/BACK в режиме съёмки) — точка вернётся в центр.

### Техника «Фокус + Перекомпоновка»

Классический приём, который должен знать каждый фотограф:

1. Наведите центральную точку на объект (например, глаз человека)
2. Нажмите кнопку спуска наполовину — камера сфокусируется
3. Не отпуская кнопку, перекомпонуйте кадр
4. Нажмите до конца — сделайте снимок

```
Шаг 1:              Шаг 2:              Шаг 3:
┌─────────┐         ┌─────────┐         ┌─────────┐
│    👁    │   →    │    👁    │    →   │      👁  │
│   [■]    │        │   [■]🔒  │        │   [■]🔒 │
│         │         │         │         │         │
└─────────┘         └─────────┘         └─────────┘
  Фокус на           Заблокирован        Кадр
  объекте                               перекомпонован
```

> ⚠️ **Важно**: Эта техника хорошо работает на закрытых диафрагмах (f/5.6 и выше). На f/2 смещение камеры может вывести объект из зоны резкости!

### Приёмы опытных фотографов

#### 1. Предварительная фокусировка (Pre-focus)

Для уличной съёмки и репортажа:
1. Заранее сфокусируйтесь на зону, где будет действие
2. Ждите момента
3. Снимайте без задержки на фокусировку

#### 2. Зонная фокусировка (Zone Focusing)

Техника для быстрой уличной съёмки:
1. Переключитесь в ручной фокус (M)
2. Установите диафрагму f/8
3. Сфокусируйтесь на расстояние ~2-3 метра
4. Всё в диапазоне 1.5-5 метров будет в резкости!

На X100VI в ручном режиме отображается шкала глубины резкости — пользуйтесь ей!

#### 3. Back Button Focus (Фокусировка задней кнопкой)

Продвинутая техника — разделяем фокусировку и съёмку:

**Настройка:**
1. `MENU → Настройка кнопок/дисков → Настройка ф-ции (Fn)`
2. Назначьте на кнопку AF-L функцию «AF-ON»
3. В `Настройка кнопок/дисков` отключите AF на кнопке спуска

**Как работает:**
- Кнопка AF-L — фокусировка
- Кнопка спуска — только съёмка

**Преимущества:**
- Можно заблокировать фокус без удержания кнопки
- Мгновенный переход от AF к предварительной фокусировке

### Автофокус для движущихся объектов

#### Настройки для съёмки движения:

1. Переключатель фокуса → **C**
2. `MENU → AF/MF → Режим AF` → **Зона** или **Широкая/Отслеживание**
3. `MENU → AF/MF → Настр. распозн. лиц/глаз` → **Вкл.** (для людей)
4. `MENU → AF/MF → Настройка AF-C` → **Set 1** (универсальный)

#### Настройки AF-C (наборы)

| Набор | Описание | Когда использовать |
|-------|----------|-------------------|
| Set 1 | Универсальный | Непредсказуемое движение |
| Set 2 | Игнорирует препятствия | Спорт, когда объект перекрывается |
| Set 3 | Для ускоряющихся объектов | Машины, велосипеды |
| Set 4 | Внезапное появление | Птицы, животные |
| Set 5 | Неустойчивое движение | Дети, питомцы |

## Часть II. Экспозамер

Экспозамер — это способ, которым камера измеряет количество света в сцене для определения экспозиции.

### Режимы экспозамера на X100VI

Путь: `MENU → Настройка съёмки → Фотометрия`

#### 1. Мультизамер (Multi)

```
┌─────────────────┐
│ ▪ ▪ ▪ ▪ ▪ ▪ ▪ │
│ ▪ ▪ ▪ ▪ ▪ ▪ ▪ │
│ ▪ ▪ ▪ ▪ ▪ ▪ ▪ │
│ ▪ ▪ ▪ ▪ ▪ ▪ ▪ │
└─────────────────┘
  Весь кадр анализируется
```

**Как работает:**
- Кадр делится на множество зон
- Камера анализирует яркость каждой зоны
- Алгоритм выбирает оптимальную экспозицию

**Когда использовать:**
- 80% ситуаций
- Пейзажи
- Групповые фото
- Когда свет равномерный

#### 2. Точечный замер (Spot)

```
┌─────────────────┐
│                 │
│       [●]       │
│                 │
└─────────────────┘
  Только центр (2% кадра)
```

**Как работает:**
- Измеряет только маленькую область в центре
- Игнорирует всё остальное

**Когда использовать:**
- Контровой свет (объект против солнца)
- Сцены с экстремальным контрастом
- Театр, концерты (освещённый артист на тёмной сцене)

**Важно:** При точечном замере лучше связать его с точкой фокусировки:
`MENU → Настройка съёмки → Связь точки АФ и замера` → **Вкл.**

#### 3. Средневзвешенный (Average)

```
┌─────────────────┐
│ · · · · · · · │
│ · · ▪ ▪ · · · │
│ · · ▪ ▪ · · · │
│ · · · · · · · │
└─────────────────┘
  Акцент на центр, но учитывает края
```

**Как работает:**
- Приоритет центральной области
- Края влияют меньше

**Когда использовать:**
- Классические портреты
- Когда объект в центре, но фон тоже важен

#### 4. Средний (Center Weighted)

Похож на средневзвешенный, но с более равномерным распределением. Используется редко.

### Какой замер выбрать?

| Ситуация | Рекомендуемый замер |
|----------|-------------------|
| Обычная съёмка, пейзаж | Мультизамер |
| Портрет на улице | Мультизамер или Средневзвешенный |
| Объект против света | Точечный |
| Снег, пляж | Мультизамер + коррекция +1 EV |
| Тёмный объект на светлом фоне | Точечный |
| Концерт, театр | Точечный |

### Быстрое переключение экспозамера

Добавьте «Фотометрия» в Q-меню для быстрого доступа:
1. Нажмите Q
2. Нажмите DISP/BACK
3. Выберите «Фотометрия» и добавьте в быстрое меню

## Часть III. Экспопара

### Что такое экспопара

Экспопара (или экспозиционный треугольник) — это соотношение трёх параметров:

```
        Диафрагма
           /\
          /  \
         /    \
        /  ◯   \
       /        \
      /__________\
  Выдержка    ISO
```

Эти три параметра вместе определяют **экспозицию** — количество света, попадающего на матрицу.

### Закон взаимозаменяемости

> 📌 **Главный принцип**: Изменение одного параметра на 1 ступень можно компенсировать изменением другого параметра на 1 ступень.

**Пример:**
Если вы снимаете при настройках:
- f/4, 1/250, ISO 400

И хотите больше размытия фона (открыть диафрагму на f/2.8), нужно компенсировать:
- f/2.8, 1/500, ISO 400 (сократили выдержку)

ИЛИ
- f/2.8, 1/250, ISO 200 (уменьшили ISO)

### Ступени экспозиции (стопы)

Каждая ступень = изменение количества света в 2 раза.

**Диафрагма (полные ступени):**
f/2 → f/2.8 → f/4 → f/5.6 → f/8 → f/11 → f/16

**Выдержка (полные ступени):**
1/30 → 1/60 → 1/125 → 1/250 → 1/500 → 1/1000

**ISO (полные ступени):**
100 → 200 → 400 → 800 → 1600 → 3200 → 6400

### Практические примеры экспопар

#### Солнечный день, пейзаж
- f/8, 1/250, ISO 200
- Много света → можно использовать низкое ISO
- Нужна большая глубина резкости → закрываем диафрагму

#### Портрет с размытым фоном
- f/2, 1/500, ISO 200
- Открытая диафрагма для размытия
- Много света → короткая выдержка компенсирует

#### Вечерняя улица без штатива
- f/2, 1/60, ISO 3200
- Мало света → всё максимально открыто
- ISO приходится поднимать

#### Ночной город со штатива
- f/8, 4", ISO 200
- Штатив позволяет длинную выдержку
- Можно держать ISO низким

### Режимы съёмки и экспопара

#### P — Program (Программный)
Камера сама выбирает диафрагму и выдержку. Вы контролируете ISO и экспокоррекцию.

#### A (Av) — Aperture Priority (Приоритет диафрагмы)
- **Вы выбираете**: диафрагму
- **Камера выбирает**: выдержку
- **Настройка на X100VI**: кольцо диафрагмы на числовое значение, кольцо выдержки на A

> 💡 **Рекомендую этот режим для новичков!** Вы контролируете глубину резкости, камера подбирает остальное.

#### S (Tv) — Shutter Priority (Приоритет выдержки)
- **Вы выбираете**: выдержку
- **Камера выбирает**: диафрагму
- **Настройка на X100VI**: кольцо диафрагмы на A, кольцо выдержки на числовое значение

Полезен для съёмки движения, когда важна конкретная выдержка.

#### M — Manual (Ручной)
- **Вы выбираете**: всё
- **Настройка на X100VI**: оба кольца на числовые значения

Для полного контроля и сложных световых условий.

### Как быстро менять параметры на X100VI

#### Физические кольца
- Диафрагма — кольцо на объективе
- Выдержка — верхнее кольцо
- Компенсация — кольцо вокруг выдержки

#### Командные диски
- Передний диск — можно назначить на ISO
- Задний диск — можно назначить на экспокоррекцию

**Моя рекомендация для быстрой работы:**
1. Установите Auto ISO
2. Кольцо компенсации используйте для коррекции
3. Диафрагму меняйте кольцом на объективе
4. Выдержку оставьте на A (автомат)

## Практическое задание

### Задание 1: Освойте режимы автофокуса

1. Снимите портрет друга/члена семьи:
   - Режим S, точечный AF, фокус на глазах
   - Используйте распознавание лиц

2. Снимите движущийся объект (машину, питомца):
   - Режим C, зона или отслеживание
   - Сделайте серию снимков

3. Попробуйте ручной фокус:
   - Включите помощник фокусировки (пикинг)
   - Сделайте фото с акцентом на определённой дистанции

### Задание 2: Эксперимент с экспозамером

1. Найдите контрастную сцену (окно в тёмной комнате)
2. Снимите её:
   - С мультизамером
   - С точечным замером по светлой области
   - С точечным замером по тёмной области
3. Сравните результаты — какой вам больше нравится?

### Задание 3: Экспопара в действии

1. Выйдите на улицу днём
2. Установите: f/8, Auto ISO
3. Снимите пейзаж и запишите параметры
4. Теперь измените на f/2.8
5. Посмотрите, как изменилась выдержка
6. Убедитесь, что экспозиция осталась такой же

## Частые вопросы

### «Камера фокусируется не на том, на чём я хочу»

**Решение:**
1. Используйте одноточечный AF вместо широкой зоны
2. Перемещайте точку джойстиком
3. Включите распознавание лиц/глаз для портретов

### «Фото слишком тёмные/светлые»

**Решение:**
1. Используйте компенсацию экспозиции (кольцо +/-)
2. Попробуйте другой режим экспозамера
3. Для сложных сцен — точечный замер по объекту

### «Какой режим автофокуса использовать по умолчанию?»

**Мой совет:**
- Режим S (одиночный) — для 80% ситуаций
- Зона или одноточечный AF
- Распознавание лиц — всегда включено
