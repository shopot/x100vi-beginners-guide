# Инструкция по деплою на Vercel

Этот проект использует Next.js для статической генерации сайта из Markdown
файлов.

## Локальная разработка

### Установка pnpm (если еще не установлен)

```bash
npm install -g pnpm
# или
curl -fsSL https://get.pnpm.io/install.sh | sh -
```

### Установка зависимостей

```bash
pnpm install
```

### Запуск dev-сервера

```bash
pnpm dev
```

> **Примечание:** Проект использует pnpm, но также работает с npm и yarn. Просто
> замените `pnpm` на `npm` или `yarn` в командах.

Сайт будет доступен по адресу http://localhost:3000

## Сборка для продакшена

```bash
pnpm build
```

Статические файлы будут в папке `out/`.

## Деплой на Vercel

### Автоматический деплой через GitHub

1. Загрузите код в GitHub репозиторий (если еще не загружен)
2. Перейдите на [vercel.com](https://vercel.com)
3. Нажмите "Add New Project"
4. Импортируйте ваш GitHub репозиторий
5. Vercel автоматически определит Next.js
6. Нажмите "Deploy"

Vercel автоматически будет деплоить каждое изменение в main ветке.

### Ручной деплой через Vercel CLI

1. Установите Vercel CLI:

```bash
pnpm add -g vercel
# или
npm i -g vercel
```

2. Войдите в аккаунт:

```bash
vercel login
```

3. Деплой:

```bash
vercel
```

## Структура проекта

- `lessons/` - уроки курса (Markdown файлы)
- `guides/` - гайды (Markdown файлы)
- `recipes/` - рецепты (Markdown файлы)
- `pages/` - страницы Next.js
- `components/` - React компоненты

Все Markdown файлы читаются напрямую из исходных папок, их не нужно перемещать
или копировать.

## Настройки Vercel

Проект настроен на статический экспорт (`output: 'export'` в `next.config.js`),
что означает:

- Полностью статический сайт
- Быстрая загрузка
- Работает на любом хостинге
- Не требует Node.js сервера
