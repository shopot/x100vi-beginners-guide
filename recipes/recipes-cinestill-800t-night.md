# CineStill 800T — X-Trans V (X100VI)

Почему именно он:

- **Кинематографичный эффект**: Эта пленка известна своим "halation" эффектом —
  легким свечением вокруг ярких источников света, что придает огням города
  волшебное, кинематографическое качество.

- **Работа с искусственным светом**: CineStill 800T сбалансирован для
  искусственного (лампового) освещения (температура около 3200K-4300K). Он
  превращает обычные уличные фонари и неон в красивые, насыщенные цвета.

- **Цветовой контраст**: Он создает потрясающий контраст между холодными
  сине-зелеными тенями и теплыми оранжево-розовыми огнями вывесок. Для горда,
  где много синего и красного неона, это идеальное попадание.

Дает ту самую "магию неона". Люди отмечают, что он превращает скучный ночной
снимок в кадр из кино 80-х. Сильные ореолы (halation) вокруг огней и контраст
теплого/холодного света.

## Настройки:

| Параметр                  | Значение                                                     |
| ------------------------- | ------------------------------------------------------------ |
| **Film Simulation**       | **ETERNA/CINEMA**                                            |
| **Dynamic Range**         | DR400                                                        |
| **Grain Effect**          | Strong, Large                                                |
| **Color Chrome Effect**   | Strong                                                       |
| **Color Chrome FX Blue**  | **Weak**                                                     |
| **White Balance**         | Fluorescent 3 (Cool White Fluorescent), **-6 Red & -4 Blue** |
| **Highlight**             | 0                                                            |
| **Shadow**                | +2                                                           |
| **Color**                 | +4                                                           |
| **Sharpness**             | -3                                                           |
| **High ISO NR**           | -4                                                           |
| **Clarity**               | -5                                                           |
| **ISO**                   | Auto, до 6400                                                |
| **Exposure Compensation** | -1/3 … +2/3 (типично)                                        |

Рецепт создан прежде всего для **ночной/вечерней съёмки** при искусственном
свете (tungsten-balanced). Днём даёт сильный синий оттенок (как и настоящая
плёнка CineStill 800T без корректирующего фильтра 85).
