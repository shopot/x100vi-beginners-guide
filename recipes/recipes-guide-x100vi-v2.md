## Как создать рецепт в Fujifilm X100VI

### Пошаговая инструкция на примере CineStill 800T

#### Шаг 1: Переход в меню Custom Settings

1. Нажмите кнопку **MENU/OK** на камере
2. Перейдите в раздел **IQ (Image Quality)** — иконка с камерой
3. Найдите пункт **Edit/Save Custom Setting**
4. Выберите слот **C4** (или любой свободный C1-C7)

#### Шаг 2: Редактирование параметров

После выбора слота, вы попадёте в меню редактирования. Настройте каждый параметр:

**2.1. Film Simulation**
- Прокрутите до пункта **Film Simulation**
- Нажмите вправо для входа в подменю
- Выберите **Eterna**
- Нажмите **MENU/OK** для подтверждения

**2.2. Grain Effect**
- Найдите **Grain Effect**
- Установите **Strength: Strong**
- Установите **Size: Large**

**2.3. Color Chrome Effect**
- Найдите **Color Chrome Effect**
- Выберите **Strong**

**2.4. Color Chrome FX Blue**
- Найдите **Color Chrome FX Blue**
- Выберите **Strong**

**2.5. White Balance**
- Перейдите к **White Balance**
- Выберите **K** (Kelvin)
- Установите **3200K**
- Нажмите вправо для точной настройки WB Shift
- Установите **R: -3** (красный сдвиг)
- Установите **B: +4** (синий сдвиг)

**2.6. Dynamic Range**
- Найдите **Dynamic Range**
- Выберите **DR200**

**2.7. Tone Curve (Highlight/Shadow)**
- Перейдите к **Tone Curve**
- **Highlight**: установите **-1**
- **Shadow**: установите **+2**

**2.8. Color**
- Найдите пункт **Color**
- Установите **+4**

**2.9. Sharpness**
- Найдите **Sharpness**
- Установите **-1**

**2.10. High ISO NR (Noise Reduction)**
- Найдите **High ISO NR**
- Установите **-4**

**2.11. Clarity**
- Найдите **Clarity**
- Установите **-2**

> **Важно:** Если Clarity недоступен (серый), проверьте:
> - Режим съёмки не должен быть CH/CL (серийная съёмка)
> - Переключатель DRIVE должен быть на S
> - Формат файла должен быть JPEG, не HEIF
> - Режим не должен быть HDR

#### Шаг 3: Настройка ISO

1. Выйдите из меню Custom Settings
2. Перейдите в **Shooting Setting** → **ISO Auto Setting**
3. Установите:
   - **Default Sensitivity**: 800
   - **Max. Sensitivity**: 12800
   - **Min. Shutter Speed**: 1/60 или Auto

#### Шаг 4: Сохранение рецепта

1. Вернитесь к **Edit/Save Custom Setting**
2. Выберите ваш слот (C4)
3. Нажмите **Q** (кнопка быстрого меню) для сохранения
4. Подтвердите сохранение

#### Шаг 5: Быстрое переключение между рецептами

1. При съёмке нажмите **Q** для быстрого меню
2. Выберите **Custom Setting**
3. Переключайтесь между C1-C7 для смены рецепта

### Советы по использованию

- **Exposure Compensation**: Рецепты указывают рекомендуемую компенсацию экспозиции (например, "0 до +2/3"). Используйте колесо коррекции экспозиции на верхней панели камеры.

- **Auto Update Custom Setting**: Если хотите, чтобы изменения настроек сохранялись автоматически:
  - **Menu** → **Set Up** → **Button/Dial Setting** → **Auto Update Custom Setting** → **On**

- **Копирование рецептов**: Создайте один базовый рецепт, затем скопируйте его в другие слоты и измените только нужные параметры.
