## Справочник параметров (на что влияет значение)

Краткая заметка в столбце «Описание» в таблицах рецептов поясняет, **на что
влияет** указанное значение параметра.

| Параметр                 | На что влияет значение                                                                                                       |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| **Film Simulation**      | Базовая «плёнка»: палитра цветов и контраст (Velvia — ярко, Classic Chrome — приглушённо, Reala Ace — естественно и т.д.).   |
| **Dynamic Range (DR)**   | Защита светов: DR200/400 сохраняют детали в ярких участках, но делают картинку чуть площе. DR100 — более «ударный» контраст. |
| **Highlight**            | Света: минус смягчает пересветы, плюс делает светлые участки ярче.                                                           |
| **Shadow**               | Тени: минус — темнее/глубже, плюс — светлее и больше деталей в тенях.                                                        |
| **Color**                | Насыщенность: выше значение — более насыщенные цвета.                                                                        |
| **Sharpness**            | Резкость контуров: минус — мягче (для «плёнки»), плюс — чётче.                                                               |
| **High ISO NR**          | Шумоподавление: −4 даёт более заметное зерно, ближе к плёнке.                                                                |
| **Clarity**              | Микроконтраст: минус — мягче/мечтательнее, плюс — жёстче; при ≠0 возможна задержка записи.                                   |
| **Grain Effect**         | Сила и размер зерна: усиливает «плёнчатый» вид.                                                                              |
| **Color Chrome Effect**  | Углубление красных и отчасти жёлтых/зелёных; добавляет объём цвету.                                                          |
| **Color Chrome FX Blue** | Насыщенность и глубина синих (небо, тени в контре).                                                                          |
| **White Balance**        | Базовая цветовая температура (Daylight, Auto, K, Fluorescent и т.д.).                                                        |
| **WB Shift (Red/Blue)**  | Сдвиг баланса: Red + — теплее, Blue − — холоднее; тон кожи и общее настроение кадра.                                         |

## 1. Easy Reala Ace — универсальный

**Назначение:** Один рецепт на весь день и любую погоду; естественные цвета и
лёгкий контраст. Идеален как основной тревел-пресет.

| Параметр             | Значение            | Описание (на что влияет значение)                                     |
| -------------------- | ------------------- | --------------------------------------------------------------------- |
| Film Simulation      | Reala Ace           | Естественная палитра и контраст; подходит при любом свете.            |
| Dynamic Range        | DR400               | Сохраняет детали в светах; уменьшает пересветы при ярком солнце.      |
| Grain Effect         | Weak, Small         | Лёгкое мелкое зерно; не отвлекает, добавляет лёгкую текстуру.         |
| Color Chrome Effect  | Strong              | Углубляет красные и жёлтые; добавляет объём цвету.                    |
| Color Chrome FX Blue | Weak                | Синие чуть глубже; на X-Trans V без перегруза.                        |
| White Balance        | Auto, 0 Red, 0 Blue | Авто подстраивается под свет; нулевой сдвиг — нейтральный тон.        |
| Highlight            | -1                  | Света мягче; меньше пересветов.                                       |
| Shadow               | 0                   | Тени без осветления; стандартная глубина.                             |
| Color                | 0                   | Насыщенность по умолчанию; без усиления.                              |
| Sharpness            | 0                   | Нейтральная резкость контуров.                                        |
| High ISO NR          | -4                  | Меньше шумоподавления → больше зерна на высоком ISO; «плёнчатый» вид. |
| Clarity              | 0                   | Без микроконтраста и без задержки записи.                             |
| ISO                  | Auto, до 6400       | Камера сама подбирает ISO; удобно в путешествии.                      |
| Экспокоррекция       | +1/3 … +1           | Рекомендуемый диапазон; для ярких сцен часто плюс.                    |

_Источник:
[Easy Reala Ace](https://fujixweekly.com/2024/06/20/easy-reala-ace-fujifilm-x100vi-x-trans-v-film-simulation-recipe/)
(Fuji X Weekly; автор рецепта — Nathalie Boucry). X100VI, X-T50._

## 2. Kodachrome 64

**Назначение:** Классический слайд — насыщенные красные и жёлтые, «солнечный»
вид. Лучше всего в ясный день.

| Параметр             | Значение                  | Описание (на что влияет значение)                                |
| -------------------- | ------------------------- | ---------------------------------------------------------------- |
| Film Simulation      | Classic Chrome            | Приглушённая база; подходит под вид слайда Kodachrome.           |
| Dynamic Range        | DR200                     | Баланс контраста и деталей в светах; меньше пересветов.          |
| Grain Effect         | Weak, Small               | Лёгкое мелкое зерно; имитация слайда.                            |
| Color Chrome Effect  | Strong                    | Усиливает красные и жёлтые; вид Kodachrome.                      |
| Color Chrome FX Blue | Off                       | На X-Trans V синие не углублять; избегаем перегруза синего.      |
| White Balance        | Daylight, +2 Red, -5 Blue | Дневной свет; сдвиг в теплоту под слайд.                         |
| Highlight            | 0                         | Света без коррекции; стандартная кривая.                         |
| Shadow               | +0.5                      | Тени чуть светлее; больше деталей в тенях.                       |
| Color                | +2                        | Насыщенность выше; более выразительные цвета.                    |
| Sharpness            | +1                        | Чуть более чёткие контуры; «слайдовый» рисунок.                  |
| High ISO NR          | -4                        | Больше зерна; плёнчатый вид.                                     |
| Clarity              | +3                        | Микроконтраст выше; «жёсткость» слайда (задержка записи при ≠0). |
| ISO                  | Auto, до 6400             | Авто ISO в диапазоне.                                            |
| Экспокоррекция       | 0 … +2/3                  | В солнечный день часто 0; при необходимости лёгкий плюс.         |

_Источник:
[Kodachrome 64](https://fujixweekly.com/2022/11/28/kodachrome-64-fujifilm-x-t5-x-trans-v-film-simulation-recipe/)

**Назначение:** Классическое чёрно-белое — контраст, зерно, подходит для улицы,
портретов и путешествий в любое время суток.

| Параметр             | Значение                  | Описание (на что влияет значение)                                                |
| -------------------- | ------------------------- | -------------------------------------------------------------------------------- |

| Grain Effect         | Strong, Large             | Крупное зерно; классический вид Tri-X.                                           |
| Color Chrome Effect  | Strong                    | Влияет на тональность в Acros; чуть больше контраста в переходах.                |
| Color Chrome FX Blue | Off                       | В Acros не используется; оставляем Off.                                          |
| White Balance        | Daylight, +9 Red, -9 Blue | В Ч/Б сдвиг задаёт оттенок; здесь — чуть холодноватый тон.                       |

## Как загрузить в камеру

1. В меню камеры: **IQ → Edit/Save Custom Setting** (или аналог для вашей
   модели).
2. Выберите слот **C1–C7**, введите параметры из таблиц выше.
3. Сохраните набор (обычно через **OK** или **Disp/Back** в зависимости от
   модели).
4. Переключение пресетов — через диск выбора режимов (C1–C7) или Q-меню.

_Подробная инструкция:
[How to Program Film Simulation Recipes to your Fujifilm Camera](https://fujixweekly.com/2024/02/27/how-to-program-film-simulation-recipes-to-your-fujifilm-camera/)._
