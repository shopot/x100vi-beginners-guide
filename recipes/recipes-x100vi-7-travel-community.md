# 7 лучших рецептов Fujifilm X100VI для тревел-фотографии

сообщества и рекомендаций фотографов. Рецепты подходят для X-Trans V (X100VI,
X-T5, X-H2 и др.) и рассчитаны на использование круглый год в путешествиях.

## Справочник параметров (на что влияет значение)

| Параметр                 | Краткое описание влияния                                                                                                     |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| **Film Simulation**      | Базовая «плёнка»: палитра цветов и контраст (Velvia — ярко, Classic Chrome — приглушённо, Reala Ace — естественно и т.д.).   |
| **Dynamic Range (DR)**   | Защита светов: DR200/400 сохраняют детали в ярких участках, но делают картинку чуть площе. DR100 — более «ударный» контраст. |
| **Highlight**            | Света: отрицательные значения смягчают пересветы, положительные — делают светлые участки ярче.                               |
| **Shadow**               | Тени: минус — темнее/глубже тени, плюс — светлее, больше деталей в тенях.                                                    |
| **Color**                | Насыщенность цветов: выше значение — более насыщенные цвета.                                                                 |
| **Sharpness**            | Резкость контуров: минус — мягче (часто для «плёнки»), плюс — чётче.                                                         |
| **High ISO NR**          | Шумоподавление на высоком ISO: −4 даёт более заметное зерно, ближе к плёнке.                                                 |
| **Clarity**              | Микроконтраст/чёткость средних тонов: минус — мягче/мечтательнее, плюс — жёстче; при ≠0 возможна задержка записи.            |
| **Grain Effect**         | Сила и размер зерна: усиливает «плёнчатый» вид.                                                                              |
| **Color Chrome Effect**  | Углубление красных и отчасти жёлтых/зелёных; добавляет объём цвету.                                                          |
| **Color Chrome FX Blue** | Насыщенность и глубина синих (небо, тени в контре).                                                                          |
| **White Balance**        | Базовая цветовая температура (Daylight, Auto, K, Fluorescent и т.д.).                                                        |
| **WB Shift (Red/Blue)**  | Сдвиг баланса: Red + — теплее, Blue − — холоднее; тон кожи и общее настроение кадра.                                         |

## 1. Easy Reala Ace — универсальный

**Назначение:** Один рецепт на весь день и любую погоду; естественные цвета и
лёгкий контраст. Идеален как основной тревел-пресет.

| Параметр             | Значение            | Описание                                        |
| -------------------- | ------------------- | ----------------------------------------------- |
| Film Simulation      | Reala Ace           | Естественная палитра, подходит везде.           |
| Dynamic Range        | DR400               | Сохраняет детали в светах при ярком солнце.     |
| Grain Effect         | Weak, Small         | Лёгкое зерно, не отвлекает.                     |
| Color Chrome Effect  | Strong              | Более насыщенные красные/жёлтые.                |
| Color Chrome FX Blue | Weak                | Синие чуть глубже, без перегруза.               |
| White Balance        | Auto, 0 Red, 0 Blue | Адаптация к любому свету без сдвига.            |
| Highlight            | -1                  | Света чуть мягче, меньше пересветов.            |
| Shadow               | 0                   | Тени без дополнительного осветления.            |
| Color                | 0                   | Насыщенность по умолчанию.                      |
| Sharpness            | 0                   | Нейтральная резкость.                           |
| High ISO NR          | -4                  | Больше зерна на высоком ISO.                    |
| Clarity              | 0                   | Без задержки записи, нейтральный микроконтраст. |
| ISO                  | Auto, до 6400       | Удобно в путешествии.                           |
| Экспокоррекция       | +1/3 … +1           | Часто полезно для ярких сцен.                   |

_Источник: Fuji X Weekly, рецепт Nathalie Boucry; для X100VI и X-T50 (нативный
Reala Ace)._

## 2. Kodachrome 64

**Назначение:** Классический слайд — насыщенные красные и жёлтые, «солнечный»
вид. Лучше всего в ясный день.

| Параметр             | Значение                  | Описание                                      |
| -------------------- | ------------------------- | --------------------------------------------- |
| Film Simulation      | Classic Chrome            | Приглушённая база, хорошо подходит под слайд. |
| Dynamic Range        | DR200                     | Баланс контраста и деталей в светах.          |
| Grain Effect         | Weak, Small               | Лёгкое зерно слайда.                          |
| Color Chrome Effect  | Strong                    | Усиление красных/жёлтых под Kodachrome.       |
| Color Chrome FX Blue | Off                       | На X-Trans V синие не углублять.              |
| White Balance        | Daylight, +2 Red, -5 Blue | Тёплый дневной сдвиг под слайд.               |
| Highlight            | 0                         | Света по умолчанию.                           |
| Shadow               | +0.5                      | Тени чуть светлее.                            |
| Color                | +2                        | Более насыщенные цвета.                       |
| Sharpness            | +1                        | Чуть более чёткий слайд.                      |
| High ISO NR          | -4                        | Зерно заметнее.                               |
| Clarity              | +3                        | Добавляет «жёсткость» слайда.                 |
| ISO                  | Auto, до 6400             | —                                             |
| Экспокоррекция       | 0 … +2/3                  | В солнечный день часто 0.                     |

_Источник: Fuji X Weekly (X-Trans V)._

## Как загрузить в камеру

1. В меню камеры: **IQ → Edit/Save Custom Setting** (или аналог для вашей
   модели).
2. Выберите слот **C1–C7**, введите параметры из таблиц выше.
3. Сохраните набор (обычно через **OK** или **Disp/Back** в зависимости от
   модели).
4. Переключение пресетов — через диск выбора режимов (C1–C7) или Q-меню.

_Подробная инструкция:
[How to Program Film Simulation Recipes to your Fujifilm Camera](https://fujixweekly.com/2024/02/27/how-to-program-film-simulation-recipes-to-your-fujifilm-camera/)._
